> **화면 표시가 다를 수 있어요.** 이 페이지는 이 사이트의 강좌 내용을 요약한 **개요**예요. 자세한 따라하기는 각 강좌에 있어요. 사이트·앱의 정책과 화면은 자주 바뀌어요.

## 1. 무엇이 되나요

**Aside 브라우저**는 Claude Code 데스크탑 앱 오른쪽 패널의 브라우저예요. 실제 인터넷 주소를 열 수 있고, 클로드가 지금 화면을 보고 안내하거나, **Computer Use** 모드로 직접 클릭·입력도 해요. ([Aside 1강](/lectures/aside/lesson-01), [2강](/lectures/aside/lesson-02))

핵심은 이 분업이에요. **사람은 로그인하고, 클로드는 나머지를 조작해요.** 그래서 내 계정이 이미 로그인된 상태에서 이런 일을 맡길 수 있어요.

- 블로그 글 입력 — 네이버 스마트에디터에 제목·본문·사진·태그 채우기 ([네이버 블로그 6강](/lectures/naver-blog/lesson-06), [Aside 9강](/lectures/aside/lesson-09))
- 유튜브 스튜디오 — 제목·설명·태그 넣고 업로드·예약 ([Aside 11강](/lectures/aside/lesson-11))
- SNS — 원본 글을 채널별로 바꿔 올리기 ([Aside 7강](/lectures/aside/lesson-07), [SNS 강좌](/lectures/sns))

**안 되거나 하지 않는 것**: 일부 사이트는 자동화를 감지해 막아요(캡차, 로그인 만료). 강좌에서도 답글·DM·팔로우·좋아요 자동화는 하지 않는다고 해요. 채널별로 자동 발행이 되는지는 해당 채널의 API 정책이 정하고, 정책은 자주 바뀐다고 안내돼 있어요. ([SNS 1강](/lectures/sns/lesson-01))

## 2. 어떤 순서로 하나요

1. **원본을 만들어요**: 글·영상 같은 원본은 사람이 먼저 정해요.
2. **클로드가 준비해요**: 키워드 조사, 초안, 채널별 변환(글자 수·말투), 제목·태그, 이미지 카드.
3. **Aside에서 직접 로그인해요.** 비밀번호는 내가 직접 입력해요.
4. **한 번에 하나씩 맡겨요**: 처음엔 글 한 편, 채널 하나로 시작해요. 첫 두 단락만 입력시켜 보고 맞으면 이어가요. (네이버 블로그 6강 방식)
5. **발행 전에 내가 확인해요**: 제목·오타·사진·서식을 직접 봐요. 네이버 블로그 강좌의 원칙은 **임시저장까지 자동, 발행은 사람이**예요. 이 원칙을 다른 채널에도 적용하는 편이 안전해요.
6. **잘 되는 절차를 저장해요**: 세 번쯤 해서 순서가 굳으면 스킬로 저장해 한 줄로 부르게 해요. ([Aside 13강](/lectures/aside/lesson-13))

클로드에게는 이렇게 시켜요.

> 지금 Aside 브라우저에 네이버 블로그 글쓰기 화면이 열려 있고 로그인돼 있어. 제목과 본문 첫 두 단락만 입력하고, **발행 버튼은 누르지 말고** 멈춰서 알려줘.

## 3. 주의할 것

- **한 번에 하나씩**: 여러 글·여러 채널을 한꺼번에 돌리지 않아요. 하루 여러 편이 기계적으로 올라가는 패턴은 검색 노출 제외(저품질)로 이어질 수 있다고 강좌가 경고해요.
- **발행 전 확인**: 클로드가 발행 버튼을 누르려 하면 즉시 멈추게 해요(`Esc`). 규칙 파일(CLAUDE.md)에 "발행은 하지 마"를 적어 둬요.
- **내 계정은 내 책임이에요**: 계정 이용 제한 위험이 있어요. 사이트의 이용 약관을 직접 읽고, 답글·DM·팔로우 자동화는 하지 않아요.
- **내 경험을 넣어요**: AI 초안을 그대로 올리면 경험 없는 글로 평가될 수 있어요. 한 단락은 직접 써요.
- **막히면 사람이**: 캡차는 내가 풀고, 로그인이 풀리면 내가 다시 로그인해요. 화면이 낯설면 [Aside 1강](/lectures/aside/lesson-01)처럼 보면서 안내받는 방식으로 돌아가요.
- 로그인 정보·API 키를 채팅에 붙여넣지 않아요. ([승인 모드와 안전장치](/skills/permissions-and-safety))

## 4. 터미널로도 할 수 있어요

강좌에서는 Playwright MCP 같은 브라우저 자동화 연결(MCP)로도 같은 작업을 해요. 터미널에서 쓰는 Claude Code에서도 연결할 수 있지만, 처음에는 데스크탑 앱의 Aside로 눈으로 보며 시작해요. ([Aside 3강](/lectures/aside/lesson-03))
