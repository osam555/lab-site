> **화면 표시가 다를 수 있어요.** 구입처마다 관리 화면이 달라요. 도메인은 **필수가 아니에요.** 버셀이 주는 `vercel.app` 주소로도 사이트는 열려요.

## 도메인이란

`mycafe.kr`처럼 사람이 외우기 쉬운 인터넷 주소예요. 이름을 사서(정확히는 일정 기간 등록해서) 내 사이트 주소로 연결해요. 보통 매년 갱신해야 하고, 가격은 **확장자(.com, .kr 등)와 구입처마다 달라서** 사기 전에 직접 비교해요.

## 어디서 얻나요

구입처를 고르는 기준만 알아 둬요. 특정 업체를 추천하지는 않을게요.

- **버셀에서 바로 구입**: 공식 문서에 버셀에서도 도메인을 살 수 있다고 안내돼 있어요. 연결이 한곳에서 끝나서 편해요.
- **도메인 전문 구입처**: 원하는 확장자가 있는지, 첫해 가격과 **갱신 가격**, 한국어 지원, 결제 수단을 비교해요.
- 이름이 이미 쓰이고 있는지는 구입처 검색창에서 확인돼요.

## 버셀에 연결하는 큰 흐름

1. 버셀 프로젝트 → **Settings → Domains → Add Domain**에서 도메인을 입력해요. `example.com`처럼 `www` 없는 주소(apex)를 넣으면 `www`도 추가하라고 안내가 나와요.
2. 버셀이 보여주는 **DNS 설정값**을 도메인 구입처의 DNS 관리 화면에 넣어요. 공식 안내 기준으로 `example.com` 같은 apex는 **A 레코드**, `docs.example.com` 같은 서브도메인은 **CNAME 레코드**예요. 값은 내 프로젝트 화면에 나온 것을 **그대로** 써요. 다른 프로젝트나 글에서 본 값을 복사하지 않아요.
3. 설정이 퍼질 때까지 시간이 걸릴 수 있어요. 버셀 화면에서 상태가 유효로 바뀌면 끝이에요.
4. 도메인 연결 상태가 "invalid"로 나오면 같은 이름의 **충돌하는 기존 레코드**가 없는지 확인해요.

DNS 화면이 낯설면 [Chrome 확장·Aside 브라우저](/lectures/homepage-cli/lesson-13)처럼 클로드가 화면을 보며 안내하게 해도 돼요. 네임서버를 통째로 바꾸는 방법은 이메일 설정이 끊길 수 있으니, 공식 문서의 주의 사항을 읽고 해요.

> 연결하려는 도메인은 `내도메인`이고 구입처는 `구입처 이름`이야. 버셀 프로젝트 Domains 화면의 값 기준으로 DNS에 뭘 넣어야 하는지 단계별로 알려줘.
