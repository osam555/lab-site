## 계정 4개

- [ ] **Claude** 계정 — Code 탭에는 유료 구독이 필요하다고 안내돼 있어요. ([클로드 기초](/basics/claude-basics))
- [ ] **GitHub** 계정 + 이메일 인증 + 2단계 인증 ([깃허브 기초](/basics/github-basics))
- [ ] **Vercel** 계정 (GitHub로 가입 권장) ([버셀 기초](/basics/vercel-basics))
- [ ] (선택) **도메인 구입처** 계정 ([도메인 기초](/basics/domain-basics))

## 설치

- [ ] **Claude 데스크탑 앱** ([claude.ai/download](https://claude.ai/download))
- [ ] **깃(Git)** — 설치 방법과 확인은 클로드에게 "내 컴퓨터에 깃이 있는지 확인하고 없으면 설치 방법을 알려줘"라고 시켜요.
- [ ] **Node.js** — 웹사이트를 만들 때 필요해요. 마찬가지로 클로드에게 확인을 시켜요.
- [ ] 코드 편집기는 없어도 시작할 수 있어요.

## 폴더

- [ ] 프로젝트마다 **폴더 하나**를 만들어요. 한글·공백 없는 이름이 안전해요(예: `my-site`).
- [ ] Code 탭에서 그 폴더를 **프로젝트 폴더**로 골라요.
- [ ] 폴더를 깃 저장소로 만들고 깃허브에 올려요. ([깃 기초](/basics/git-basics))

## 프롬프트 습관

- [ ] **무엇을, 누구를 위해, 어떤 모양으로** 말해요. ([프롬프트 잘 쓰는 법](/skills/prompt-writing))
- [ ] 큰 일은 **계획부터** 받아요. ([계획 먼저, 코드는 나중에](/skills/plan-mode-and-context))
- [ ] 한 번에 한 가지씩 시키고, **잘 되면 커밋**해요.
- [ ] 클로드의 권한 요청을 **읽고** 수락해요. ([승인 모드와 안전장치](/skills/permissions-and-safety))
- [ ] 막히면 **에러 메시지를 통째로** 보여줘요. ([에러 디버깅하는 법](/skills/error-debugging))
- [ ] 비밀번호·키는 채팅이나 깃허브에 올리지 않아요.
