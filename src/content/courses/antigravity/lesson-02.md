> **화면 표시가 다를 수 있어요.** 다운로드 화면과 버전 번호는 수시로 바뀌어요. 아래는 공식 문서에서 확인한 내용이에요(확인일 2026-10-06).

## 먼저 내 컴퓨터가 되는지

공식 Getting started 문서의 **Antigravity 2.0** 요구사항이에요.

| 운영체제 | 공식 요구사항 |
|---|---|
| macOS | 12(Monterey) 이상. 애플 실리콘과 인텔용이 따로 있어요(문서에 "x86 is not supported"라는 문구도 있어 정확한 대응은 다운로드 화면에서 확인하세요) |
| Windows | Windows 10(64비트) 이상. x64·ARM64 선택 |
| Linux | glibc 2.28 이상 등 (Ubuntu 20 이상 등). x64·ARM64 |
| Googlebook | Googlebook OS (구글 플레이에서 설치) |

> 내 맥이 애플 실리콘인지 모르면: 화면 왼쪽 위 사과 메뉴 → **이 Mac에 관하여**에서 칩 이름을 봐요. 이 강좌는 Windows와 macOS 기준이에요.

## 내려받고 설치하기

1. 브라우저에서 **antigravity.google/download** 를 열어요.
2. 내 운영체제 탭에서 내 컴퓨터에 맞는 버튼(예: Apple Silicon / Intel, x64 / ARM64)을 눌러 내려받아요.
3. 내려받은 파일을 열어 설치해요.
4. 설치 중에 "Keep Both(둘 다 유지)" 또는 "Replace(바꾸기)" 알림이 뜨면 공식 안내대로 **Replace**를 골라요. IDE를 다시 설치하겠냐고 물으면, 지금은 건너뛰어도 되고 나중에 다운로드 페이지에서 받을 수 있어요.

이 다운로드 페이지에는 CLI·IDE·SDK도 같이 있어요. 지금은 **Antigravity 2.0만** 받으면 돼요. 용량·버전 번호는 확인하지 않았어요.

## 로그인과 계정 조건

공식 FAQ에서 확인한 조건이에요. 로그인이 막히면 여기부터 봐요.

- **개인 구글 계정**이 대상이에요. 구글 워크스페이스(회사·학교) 계정이 안 되면 `@gmail.com` 계정으로 해 보라고 안내돼 있어요.
- **만 18세 미만은 사용할 수 없어요.** 나이가 '미확인'으로 뜨면 나이 인증을 하라고 안내돼 있어요.
- **지역 제한**이 있어요. 공식 목록에 **대한민국(South Korea)** 이 들어 있어요. 목록에 없는 나라면 쓸 수 없어요.
- 구글 서비스 약관에 설정된 **국가**가 실제와 다르면, 국가 변경을 요청하라고 안내돼 있어요.

용어: **로그인(sign in)** 은 "나는 이 계정의 주인이다"를 확인하는 과정이에요. 비밀번호는 구글 화면에서만 입력하고, 남에게 알려 주지 않아요.

> 2.0 앱 첫 실행 때 정확히 어떤 순서로 화면이 나오는지는 공식 문서에 적혀 있지 않아서 **여기에 쓰지 않았어요.** 화면의 안내를 따라 구글 계정으로 로그인하세요. (CLI는 브라우저가 열려 로그인하는 방식이 문서에 있어요.)

## 데이터 수집 설정

공식 FAQ는 데이터 수집에 대해 약관을 읽어 보라고 하고, **설정(Settings) 패널에서 언제든 끌 수 있다**고 안내해요. 처음 쓸 때 한 번 확인해 두세요.

::: practice
- [ ] 내 운영체제와 칩(또는 x64/ARM64)에 맞는 파일을 내려받았다
- [ ] 설치를 마치고 앤티그래비티 2.0을 열었다
- [ ] 구글 계정으로 로그인했다 (안 되면 위 조건 네 가지를 하나씩 확인했다)
- [ ] 설정에서 데이터 수집 항목이 어디 있는지 찾아봤다
:::
