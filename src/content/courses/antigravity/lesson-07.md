> **화면 표시가 다를 수 있어요.** 공식 문서에서 확인한 내용만 적었어요(확인일 2026-10-06). 두 도구의 우열이 아니라 **쓰는 법**을 정리한 강의예요.

## 같은 폴더를 두 도구로 열어도 돼요

폴더는 그냥 폴더라서 클로드 데스크탑에서 만든 `my-site`를 앤티그래비티 프로젝트로 연결해도 돼요. 단, **두 도구가 같은 파일을 동시에 고치지 않게** 한 번에 한 도구만 시키세요. 시키기 전에는 깃으로 저장해 두세요(6강).

## 언제 무엇을 쓰나

| 상황 | 추천 | 이유 |
|---|---|---|
| 이 강좌의 다른 과정을 처음 따라 할 때 | **클로드 데스크탑** | 모든 과정의 기본 도구예요 |
| 계획서를 읽고 댓글로 고쳐 가며 만들고 싶다 | 앤티그래비티 | 구현 계획·댓글·Proceed 흐름이 기본이에요 |
| 만든 화면을 에이전트가 브라우저로 열어 캡처까지 해 주길 바란다 | 앤티그래비티 | 브라우저 서브에이전트가 있어요 |
| 여러 일을 동시에(병렬로) 시키고 싶다 | 앤티그래비티 | 여러 에이전트·워크트리를 공식 지원해요 |
| 매일 같은 시각에 일을 시키고 싶다 | 앤티그래비티 | 예약 작업(scheduled tasks)이 있다고 안내돼요 |
| 한도에 걸려서 더 못 시킨다 | 다른 도구로 | 두 도구는 한도가 따로예요 |
| 내가 쓰는 규칙 파일(CLAUDE.md)·스킬을 그대로 쓰고 싶다 | 클로드 데스크탑 | 앤티그래비티는 자체 규칙(Rules)·스킬을 써요. 호환 여부는 확인하지 못했어요 |

자세한 비교는 [기초지식: 앤티그래비티와 클로드](/basics/antigravity-basics)에 있어요.

## 한 가지 꼭 지킬 것 — 로그인 공유 금지

공식 FAQ는 **클로드 코드 같은 제3자 소프트웨어에서 앤티그래비티 로그인으로 접근하는 것은 약관 위반**이고 계정이 정지될 수 있다고 안내해요. 제미나이를 다른 코딩 도구에서 쓰려면 Gemini Enterprise 또는 Google AI Studio API 키를 쓰라고 해요. 즉 **두 도구를 섞어 쓰는 건 "각각 따로 로그인해서 따로 쓰기"** 까지만 하세요.

## 권한 설정, 안전하게 두기

에이전트는 파일을 만들고 명령을 실행해요. 그래서 **권한 프리셋(permission preset)** 이 중요해요. 공식 문서(macOS·Linux)의 세 가지예요.

| 프리셋 | 설명 | 초보 |
|---|---|---|
| **Default** | 명령은 격리된 **터미널 샌드박스(sandbox)** 안에서는 묻지 않고 실행, 밖에서는 승인 필요. 작업 폴더와 임시 폴더만 읽고 쓰기 | **이대로** |
| **Request Review** | 샌드박스를 끄고, 모든 터미널 명령에 승인을 받아요 | 더 조심하고 싶을 때 |
| **Turbo** | 모든 명령을 묻지 않고 실행, 컴퓨터 전체를 읽고 쓰기 | **쓰지 마세요** |

용어: **샌드박스**는 에이전트가 명령을 실행해도 컴퓨터의 중요한 곳에 닿지 못하게 가둔 안전 구역이에요. Windows는 설정 방식이 달라서, 공식 문서에 따르면 터미널 명령 실행 방식(Request Review / Proceed in Sandbox / Always Proceed)을 고르고, **Always Proceed는 피하세요.**

설정은 **Settings > General > Permission Settings**에서 바꾸고 프로젝트마다 덮어쓸 수 있어요. 에이전트는 기본적으로 프로젝트의 폴더 안에서만 읽고 써요. 폴더 밖 접근은 신중하게 허용해야 한다고 공식 문서가 경고해요.

## 두 도구 공통 안전 습관

1. 지우기·외부 전송·결제·계정 입력은 **하기 전에 나에게 묻게** 해요.
2. 큰 수정 전에는 깃으로 저장해요.
3. 비밀번호·API 키는 대화에 붙여 넣지 않아요. ([안전과 비용](/basics/vibe-safety-money))
4. 한 번에 한 가지만 시켜요. ([한 조각씩](/skills/one-slice-loop))

::: practice
- [ ] 같은 일(예: 연락처 문구 바꾸기)을 두 도구로 한 번씩 시켜 보고 차이를 한 줄로 적었다
- [ ] 앤티그래비티 설정에서 권한 프리셋이 Default(또는 Request Review)인 것을 확인했다
- [ ] 내가 자주 하는 일 세 가지를 위 표에 따라 어느 도구에 맡길지 정했다
- [ ] 클로드 코드를 앤티그래비티 로그인으로 쓰면 안 된다는 것을 이해했다
:::
