## 이 과정에서 만드는 것

구글의 에이전트형 개발 도구 **앤티그래비티(Google Antigravity) 2.0** 으로 한 페이지 소개 사이트를 만들고, 결과를 확인하고, 깃에 저장합니다. 이 강좌의 기본 도구는 **클로드 데스크탑**이고, 앤티그래비티는 **두 번째 도구**로 배웁니다. 내용은 공식 문서(antigravity.google)에서 확인한 범위만 담았고, 확인일은 2026-10-06입니다. 화면은 자주 바뀔 수 있어요.

## 전체 흐름 (강별 한 줄)

| 부 | 강 | 한 줄 요약 |
|---|---|---|
| 1부 알아보기 | 1 앤티그래비티가 뭐고 클로드와 어떻게 다른가 | 2.0·CLI·IDE·SDK, 클로드 데스크탑과 비교 |
| | 2 설치와 첫 실행·로그인 | 운영체제 요구사항, 계정·나이·지역 조건 |
| | 3 화면 익히기와 첫 지시 | 프로젝트, 로컬/워크트리, 계획/빠른 모드, 모델 |
| 2부 만들기 | 4 홈페이지 만들기 실습 | 폴더→지시→계획 읽기→결과 확인→수정 |
| | 5 결과 확인·검토·되돌리기 | 산출물(계획·워크스루·스크린샷), 브라우저 확인, 변경 버리기 |
| 3부 올리고 쓰기 | 6 깃·버셀로 올리기 | VCS 패널로 커밋·푸시, 버셀은 기초지식 연결 |
| | 7 클로드와 같이 쓰기 | 언제 무엇을 쓰나, 권한 프리셋, 로그인 공유 금지 |
| | 8 자주 막히는 것 | 공식 FAQ 기준 확인 순서 |

## 실습 결과물

- 앤티그래비티 프로젝트에 연결된 `my-site` 폴더 (`index.html`, `style.css`)
- 계획서에 단 댓글, 브라우저 캡처, 깃 커밋 1개

## 준비물

| 것 | 설명 |
|---|---|
| 컴퓨터 | macOS 12 이상, Windows 10(64비트) 이상 등 (2강) |
| 개인 구글 계정 | 만 18세 이상, 지원 지역 (2강) |
| 클로드 데스크탑 앱 | 비교용. 기본 도구 |
| 시간 | 강마다 20~45분 |

## 끝나면 할 수 있는 것

- 앤티그래비티의 종류와 클로드 데스크탑과의 차이를 설명할 수 있다
- 프로젝트를 만들고 계획을 읽은 뒤 진행·수정시킬 수 있다
- 에이전트가 만든 산출물과 브라우저 캡처로 결과를 확인할 수 있다
- 안전한 권한 설정을 유지하며 깃에 저장할 수 있다
