## 스킬이란

**스킬(Skill)**은 Claude Code에게 "이런 상황에서는 이렇게 해줘"를 파일로 정의해두는 방법입니다.

- 복잡한 파이프라인을 매번 긴 프롬프트로 설명하지 않아도 됩니다
- 파일 하나에 저장해두면 **"SNS 배포 스킬 써줘"** 한 마디로 전체 실행
- 팀원과 공유하거나 나중에 수정하기도 쉽습니다

```
.agents/
  skills/
    sns-deploy/
      SKILL.md        ← SNS 배포 파이프라인 정의
    youtube-upload/
      SKILL.md        ← 유튜브 업로드 파이프라인 정의
    blog-post/
      SKILL.md        ← 블로그 포스팅 파이프라인 정의
```

---

## 스킬 파일 구조

SKILL.md는 두 부분으로 구성됩니다.

```markdown
---
name: SNS 배포
description: 원본 콘텐츠를 5개 채널 형식으로 변환하고 예약 배포합니다.
---

# SNS 배포 스킬

[이 아래에 Claude가 따라야 할 지시사항을 상세히 작성]
```

- `name`: 스킬 이름 (호출할 때 사용)
- `description`: 언제 이 스킬을 쓸지 설명

## 스킬 1 — SNS 배포

> 내 프로젝트 루트에 .agents/skills/sns-deploy/SKILL.md 파일을 만들어줘.
> 아래 파이프라인을 스킬로 정의해줘:

Claude Code에게 다음 내용으로 파일을 만들게 합니다:

```markdown
---
name: SNS 배포
description: 원본 콘텐츠(글·이벤트·신메뉴 등)를 받아 5개 채널에 자동 배포합니다.
---

# SNS 배포 스킬

## 입력값
사용자가 제공하는 것:
- 원본 내용 (텍스트)
- 이미지 경로 (없으면 생략)
- 예약 날짜와 시간 (없으면 내일 오전 10시)

## 실행 단계

### 1. 채널별 텍스트 변환
sns-rules.md를 읽어서 채널별 규칙을 파악한다.
원본을 아래 형식으로 변환한다:
- 인스타그램: 이모지 풍부, 해시태그 15개, 150자 이내 캡션
- X (트위터): 280자 이내, 해시태그 2개
- 스레드: 500자, 대화체
- 카카오채널: 구어체 500자, CTA 포함
- 카카오 알림: 30자 이내

### 2. 이미지 카드 생성 (이미지가 있는 경우)
인스타그램용 1:1 이미지 카드를 생성한다.
파일명: images/sns-[날짜].jpg

### 3. 인스타그램 예약 (Computer Use)
Aside 브라우저로 크리에이터 스튜디오에 접속해서
인스타그램 게시물을 예약한다.

### 4. 카카오채널 예약 (Computer Use)
Aside 브라우저로 카카오 비즈니스에 접속해서
채널 메시지를 예약한다.

### 5. X·스레드 텍스트
클립보드에 복사하고 사용자에게 알린다.

## 완료 보고
각 채널 처리 결과를 표로 정리해서 보고한다.
```

### 스킬 호출 방법

```
SNS 배포 스킬을 써줘.
원본: 이번 주 토요일 오전에 플리마켓 참가합니다. 핸드메이드 소품 20% 할인.
이미지: images/market.jpg
예약: 금요일 오후 6시
```

## 스킬 2 — 유튜브 업로드

> .agents/skills/youtube-upload/SKILL.md 파일을 만들어줘.

```markdown
---
name: 유튜브 업로드
description: 영상 파일과 주제를 받아 유튜브와 쇼츠를 최적화해서 예약 업로드합니다.
---

# 유튜브 업로드 스킬

## 입력값
- 주제 또는 영상 설명 (텍스트)
- 롱폼 영상 파일 경로
- 쇼츠 영상 파일 경로 (없으면 생략)
- 예약 날짜 (없으면 내일)

## 실행 단계

### 1. 유튜브 SEO 키워드 조사
Brave Search MCP로 주제 관련 유튜브 상위 영상 제목을 분석한다.
자주 쓰이는 키워드 패턴을 파악한다.

### 2. 메타데이터 생성
- 제목 3가지 후보 (50자 이내)
- 설명 (첫 2줄 키워드 포함, 300자 이상, 챕터 타임스탬프)
- 태그 30개
- 해시태그 15개
사용자에게 제목을 선택하게 한다.

### 3. 썸네일 생성
1280×720 썸네일 2가지를 생성한다.
파일명: thumbnails/thumb-A.jpg, thumb-B.jpg

### 4. YouTube Studio 업로드 (Computer Use)
Aside 브라우저로 YouTube Studio에 접속해서:
- 롱폼 영상 업로드, 선택한 제목·설명·태그·썸네일 적용, 예약
- 쇼츠 영상이 있으면 별도 업로드, 제목에 #Shorts 포함

### 5. 인스타 릴스 예약 (쇼츠가 있는 경우, Computer Use)
크리에이터 스튜디오에서 릴스 예약.

## 완료 보고
유튜브 영상 URL, 쇼츠 URL, 썸네일 파일 경로를 보고한다.
```

### 스킬 호출 방법

```
유튜브 업로드 스킬을 써줘.
주제: 강남 숨은 카페 5곳 추천
롱폼: ~/Desktop/videos/cafe-tour.mp4
쇼츠: ~/Desktop/videos/cafe-shorts.mp4
예약: 이번 주 금요일
```

## 스킬 3 — 블로그 포스팅

> .agents/skills/blog-post/SKILL.md 파일을 만들어줘.

```markdown
---
name: 블로그 포스팅
description: 키워드를 받아 리서치·초안·에디터 입력까지 완료합니다. 발행은 사람이 합니다.
---

# 블로그 포스팅 스킬

## 입력값
- 키워드 또는 주제
- 블로그 플랫폼 (네이버 / 티스토리 / 둘 다)

## 실행 단계

### 1. 키워드 분석
Brave Search MCP로 해당 키워드의 네이버 블로그 상위 글 구조를 분석한다.
차별화 포인트를 찾는다.

### 2. 초안 작성
SEO 최적화 초안을 작성한다.
- 제목: 키워드 포함, 클릭 유도
- 본문: 1500자 이상, 소제목 4개
- 이미지 자리표시자 3곳
- 태그 10개
blog-drafts/ 폴더에 저장한다.

### 3. 네이버 스마트에디터 입력 (Computer Use)
Playwright MCP 또는 Aside Browser Computer Use로
초안을 스마트에디터에 입력하고 임시저장한다.

### 4. 티스토리 발행 (요청 시)
티스토리 API 스크립트로 비공개 발행한다.

## 완료 보고
임시저장 완료, 사용자에게 검토 후 발행하라고 안내한다.
```

### 스킬 호출 방법

```
블로그 포스팅 스킬을 써줘.
키워드: 강남 카페 추천
플랫폼: 네이버, 티스토리
```

## 스킬 4 — 전체 콘텐츠 배포 (마스터 스킬)

세 스킬을 하나로 묶는 마스터 스킬입니다.

> .agents/skills/content-deploy/SKILL.md 파일을 만들어줘.

```markdown
---
name: 전체 콘텐츠 배포
description: 원본 하나로 블로그·SNS·유튜브를 한 번에 배포합니다.
---

# 전체 콘텐츠 배포 스킬

## 입력값
- 원본 콘텐츠 또는 주제
- 영상 파일 경로 (있는 경우)
- 배포 범위: 블로그 / SNS / 유튜브 / 전체

## 실행 단계
1. 블로그 포스팅 스킬 실행
2. SNS 배포 스킬 실행 (블로그 글 요약 사용)
3. 유튜브 업로드 스킬 실행 (영상이 있는 경우)

각 스킬을 순서대로 실행하고 결과를 통합 보고한다.
```

### 마스터 스킬 호출

```
전체 콘텐츠 배포 스킬을 써줘.
주제: 겨울 신메뉴 출시 — 뱅쇼 라떼
이미지: images/vin-chaud.jpg
영상: ~/Desktop/videos/new-menu.mp4
배포 범위: 전체
```
