## 이미 있는 방법 위에서 해요

업로드와 채널 확장은 이 사이트의 세 과정이 다뤄요. 이 강은 책 홍보에 맞춰 순서만 정리해요.

- 유튜브 스튜디오 업로드·예약: [Aside 11강](/lectures/aside/lesson-11)
- 여러 채널로 변환·예약: [SNS 배포 자동화](/lectures/sns), [Aside 7강](/lectures/aside/lesson-07)
- 블로그 글: [네이버 블로그 자동화](/lectures/naver-blog), 개요는 [Aside로 SNS 자동화 개요](/basics/aside-sns-overview)

**Aside**는 클로드 데스크탑 앱 오른쪽 패널의 브라우저예요. 사람이 로그인하고, 클로드가 화면을 보고 입력을 도와요. 비밀번호는 내가 직접 입력해요.

## 유튜브 업로드와 예약

Google 공식 도움말 기준으로 컴퓨터에서 올리는 순서는 이래요. YouTube Studio에 로그인 → **만들기** → **동영상 업로드** → 파일 선택 → 세부정보 입력 → **공개 상태** 화면에서 선택. 공개 상태에서는 바로 올리는 방식(비공개·일부 공개·공개)과 **예약**이 있어요. 예약을 고르면 날짜와 시각을 정하고, 그 시각까지는 비공개로 있다가 공개돼요. 화면 이름과 위치는 바뀔 수 있어서, 막히면 최신 [YouTube 고객센터](https://support.google.com/youtube)를 확인해요. 세로 영상은 최대 3분까지 쇼츠로 올릴 수 있고 최대 해상도는 1080p라는 안내도 있어요.

### 연습은 비공개로

> 지금 Aside 브라우저에 studio.youtube.com이 열려 있고 로그인돼 있어. `out/book-shorts-001.mp4`를 올리고 제목은 `out/001-meta.md`의 내가 고른 제목, 설명은 같은 파일 내용, 썸네일은 `out/001-thumb.jpg`로 채워줘. 공개 상태는 **비공개**로 하고, **저장이나 예약 확정 버튼은 누르지 말고** 화면을 보여주고 멈춰줘.

화면을 직접 보고 제목·설명·썸네일을 확인해요. 설명의 구매 링크가 눌러지는지도 봐요. 이상이 없으면 이번에는 내가 **예약**을 고르고 날짜·시각을 정해요. 처음 몇 번은 확정 버튼을 내 손으로 눌러요. 익숙해져서 클로드에게 예약까지 맡길 때도 **날짜와 시각은 내가 정해 주고**, 올라간 결과를 확인해요.

### 터미널로도 할 수 있어요

터미널의 Claude Code에서도 같은 일을 시킬 수 있어요. 브라우저를 연결하는 방법(Playwright MCP 등)은 [Aside 3강](/lectures/aside/lesson-03)에 있고, 처음에는 데스크탑 앱의 Aside로 눈으로 보며 시작해요.

## 하루 한 편, 같은 시각

예약 시각을 매일 같게 두면 루틴이 만들어져요. 한 번에 여러 편을 같은 시각에 올리지 말고 **하루 한 편씩 날짜를 나눠** 예약해요. 어느 시각이 더 반응이 좋은지는 책마다 달라서 올려 보며 정해요.

## 블로그와 SNS로 넓히기

같은 쇼츠를 다른 채널에도 써요.

1. **블로그**: 영상 속 한 문장과 짧은 해설, 책 소개, 구매 링크를 글로 만들어요. 네이버 블로그 강좌의 원칙은 **임시저장까지 자동, 발행은 사람이**예요.
2. **SNS**: [SNS 배포 자동화](/lectures/sns)처럼 채널별 글자 수와 말투로 바꿔 예약해요. 영상 첫 장면 카드를 이미지로 같이 쓸 수 있어요.

> `out/001-meta.md`와 `picks/book-shorts-001.md`를 바탕으로 블로그 초안 한 편과 SNS용 짧은 글 세 가지를 만들어줘. 책 홍보라는 사실이 보이게 하고, 효과 보장 표현은 쓰지 말고, 즉시 게시는 하지 말고 초안 파일로만 저장해줘.

**하지 않는 것**: 답글·DM·팔로우·좋아요 자동화는 하지 않아요(Aside 개요와 SNS 강좌의 원칙이에요). 하루 여러 편이 기계적으로 올라가는 패턴은 노출에 불리할 수 있다는 경고가 블로그 강좌에 있어요. 각 서비스의 이용 약관과 자동화 허용 범위는 내가 직접 확인해요.

::: practice
- [ ] 쇼츠 한 편을 YouTube Studio에 **비공개**로 올리고 제목·설명·썸네일을 화면에서 직접 확인했다
- [ ] 설명의 구매 링크를 눌러 열리는지 확인했다
- [ ] 공개 상태에서 **예약**을 직접 선택해 날짜·시각을 정해 보았다(실제 확정은 내가 판단해서)
- [ ] 블로그 초안 한 편이 파일로 만들어졌고 게시하지 않았다
:::
