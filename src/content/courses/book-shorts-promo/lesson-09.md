> **이 강은 개념 수업이에요.** 이 사이트에는 아직 챗봇 과정이 없어요. 구체적인 설치와 설정은 **별도 챗봇 과정을 준비 중**이에요. 여기서는 큰 그림과 지켜야 할 선만 다뤄요. 따라 할 수 있는 단계별 실습은 없어요.

## 무엇을 하려는 건가요

책을 홍보할 때 단톡방(오픈채팅방)에 정해진 시각에 "오늘의 책 속 한 문장"과 구매 링크를 보내는 방법이 있어요. 매번 손으로 올리면 하루 한 번도 꾸준히 하기 어려워서, 미리 준비해 둔 글을 시각에 맞춰 대신 보내 주는 **챗봇**을 쓰는 거예요. 챗봇은 사람 대신 메시지를 보내거나 답하는 프로그램이에요.

## 큰 그림 네 조각

방장이 자기 방에서 이런 시스템을 쓴다고 할 때, 개념 수준의 구성은 이래요.

```
① 발송 대기열      ② 발송 시각 설정     ③ 전송 담당 기기·앱
보낼 글·링크를      언제 보낼지         부계정이 로그인된
순서대로 쌓아 둔    (요일·시각)         공기계 + 메신저봇 계열 앱
서버의 목록
        └──────────────→ 시각이 되면 목록에서 하나 꺼내 방에 전송
```

- **발송 대기열**: 보낼 글을 줄 세워 둔 목록이에요. 7강의 `queue.md`와 비슷한 생각이에요. 다만 사람이 확인한 글만 올려요.
- **발송 시각 설정**: 평일 아침처럼 정해 두면 방에 일정한 리듬이 생겨요.
- **부계정 공기계**: 홍보용 계정으로 로그인한 별도 휴대폰이에요. 내 주 계정과 분리해서, 문제가 생겨도 내 일상 계정이 영향받지 않게 하려는 거예요.
- **메신저봇 앱**: 공기계에서 돌면서 시각이 되면 방에 글을 보내는 역할을 하는 앱이에요.
- 책 쇼츠를 만들고 카톡방에 홍보를 자동 발송하는 시스템은 실제로 만들어 쓰고 있는 사례가 있어요. 이 강에서는 그것이 **가능한 흐름**이라는 사실과 구성만 소개해요.

각 조각을 실제로 어떻게 설치하고 연결하는지는 이 과정에서 다루지 않아요.

## 반드시 지켜야 할 선

이 부분이 기술보다 중요해요.

1. **내 방에만 보내요.** 방장인 내가 운영하는 방에만 보내요. 다른 사람의 방에 몰래 홍보를 올리는 일은 하지 않아요.
2. **방 규칙과 동의를 지켜요.** 방 공지에 "책 홍보 글이 정해진 시각에 올라온다"는 사실을 알리고, 불편해하는 사람이 있으면 줄이거나 멈춰요.
3. **하루 횟수를 제한해요.** 하루 한 번처럼 낮게 시작해요. 많이 보낸다고 좋은 것이 아니에요. 대화가 묻히면 사람들이 나가요.
4. **광고임을 표시해요.** 홍보 글은 "[광고]" 같은 표시로 광고임이 분명히 보이게 해요. 정확한 법령상 의무는 내가 직접 확인해요.
5. **서비스 정책을 확인해요.** 카카오톡과 오픈채팅의 이용약관·운영정책에서 자동 발송이 허용되는지, 계정 제한 위험은 없는지 내가 직접 읽고 판단해요. 이 사이트는 그 정책을 확인해 주지 않아요.
6. **계정 정보는 비밀로 해요.** 부계정 비밀번호나 토큰은 채팅과 글 파일에 쓰지 않고, 이 과정에서도 입력하지 않아요([안전·비용·계정](/basics/vibe-safety-money)).
7. **사람이 확인한 글만 보내요.** 보낼 글은 대기열에 올리기 전에 내가 읽고, 효과 보장 표현이 없는지 봐요.

## 클로드에게 시킬 수 있는 일

개념 수준에서 클로드는 **글 준비**를 도와요. 구현 전이라도 이런 준비는 해 둘 수 있어요.

> `picks/queue.md`의 확정 대본 #001~#005를 바탕으로 단톡방에 올릴 짧은 안내 글을 만들어줘. 형식은 "[광고] 오늘의 책 속 한 문장" + 한 문장 + 설명란 링크 안내야. 글자 수는 짧게, 효과 보장 표현은 없이. 파일로만 저장하고 어디에도 보내지 마.

터미널로도 할 수 있어요. 같은 문장을 입력해요.

## 이 강에서 만들 것은 규칙표예요

기술 구현 대신, 내 방의 **발송 규칙표**를 글로 적어 둬요. 나중에 챗봇 과정이 나오면 이 표를 그대로 쓸 수 있어요.

| 항목 | 내 값 |
|---|---|
| 보낼 방 | (내가 운영하는 방) |
| 방 공지에 알릴 문구 | |
| 하루 최대 횟수 | |
| 보낼 요일·시각 | |
| 광고 표시 문구 | |
| 중단 조건(불편 의견이 몇 번 나오면 멈추나) | |

::: practice
- [ ] 위 일곱 가지 선을 읽고 "내 방에서는 어떻게 지킬지" 한 줄씩 적었다
- [ ] 발송 규칙표를 `routine/chat-rules.md`에 직접 채웠다

:::
