## 영상이 쓰는 도구와 방식 (먼저 알아 두기)

| 물음 | 영상의 답 |
|---|---|
| 어디서 만드나요 | 클로드 **채팅 화면의 아티팩트** 기능이에요. Code 탭이 아니에요 |
| 코딩을 해야 하나요 | 아니에요. 말로 설명하면 클로드가 코드를 만들어요 |
| 어떻게 공개하나요 | 만든 결과를 **HTML 파일로 내려받아** 깃허브에 올리고 **깃허브 페이지**로 공개해요 |
| 돈이 드나요 | 영상은 깃허브를 무료 공개 방법으로 소개해요. 클로드는 무료로도 되지만 한도와 이미지 문제가 있다고 해요(4강) |

아티팩트는 **클로드가 만든 웹사이트·문서·코드를 화면 오른쪽에서 바로 보고 고칠 수 있는 기능**이라고 영상이 설명해요. 아티팩트 개념은 [클로드 활용법](/basics/claude-uses)에도 정리되어 있어요.

## 따라 하는 순서

1. 클로드 채팅 화면을 열고, 왼쪽 메뉴에 **아티팩트** 항목이 보이는지 봐요.
2. 안 보이면 영상처럼 왼쪽 아래 **내 프로필 → 설정 → 기능**으로 가서, 아티팩트 관련 항목(시각 자료의 아티팩트와 인라인 시각화)이 켜져 있는지 확인해요. 정확한 화면과 글자는 버전마다 달라요. **영상 1:01~1:21 구간에서 확인하세요.**
3. 아티팩트 화면에 들어가 **새 아티팩트**를 눌러요. 여러 종류가 나오면 **웹사이트 쪽**을 골라요. 이름이 영상과 다르게 보이면 영상 1:36~1:52를 다시 봐요.

> 영상 제작자는 유료 버전에서는 안내 화면이 조금 다르게 보일 수 있다고 말해요. 내 화면이 다르면 당황하지 말고 영상의 흐름만 따라가요.

## 안전 한마디

클로드에게 내 전화번호·집 주소를 소개글에 넣으라고 하면 나중에 **인터넷에 그대로 공개**돼요. 공개해도 되는 정보만 쓰세요.

::: practice
- [ ] 영상 0:00~1:52를 한 번 끝까지 본다(필요하면 0.75배속)
- [ ] 클로드 채팅에서 왼쪽 메뉴의 **아티팩트**를 찾았다(없으면 설정에서 켠 뒤 다시 찾았다)
- [ ] 새 아티팩트에서 웹사이트 종류를 골라 입력창이 열린 상태다
- [ ] 이 과정이 Code 탭이 아니라 채팅의 아티팩트로 시작한다는 것을 말할 수 있다
:::
