## 깃허브가 뭔가요

영상의 설명으로는 앱이나 웹사이트 파일을 **저장하고 공유하고 관리하는 온라인 공간**이에요. 우리 사이트의 [깃허브 기초](/basics/github-basics)가 같은 내용을 쉽게 풀어 놔요.

## 영상 순서

1. 검색해서 **깃허브**에 들어가요. 처음이면 **가입(Sign up)**을 하고, 영상에서는 구글 계정으로 가입·로그인해요. (계정 만들기와 비밀번호 입력은 **내가 직접** 해요.)
2. 먼저 **내 저장소(repository)**를 만들어요. 새로 만들기를 고르고, 이름은 **영어로** 입력해요. 영상 제작자는 자기 채널 이름에 맞춘 짧은 영어 이름을 썼어요.
3. 공개 범위가 **Public(공개)**인지 확인한 뒤 **Create(만들기)**를 눌러요. 그러면 내 저장소가 생겨요.
4. 저장소 화면에서 **기존 파일 업로드(uploading an existing file)** 링크를 눌러요.
5. 4강에서 내려받은 파일을 올려요. 단, **그냥 올리지 말고 파일 이름을 `index.html`로 바꿔요.** 영상은 파일을 오른쪽 클릭해 이름 바꾸기로 바꿨어요. 이 이름이어야 주소를 열었을 때 첫 화면으로 나와요.
6. 업로드가 되면 **Commit changes**(변경 저장)를 눌러 마쳐요. 파일이 저장소에 올라간 것을 확인해요.

> 내 홈페이지 주소가 정확히 어떤 모양인지는 영상이 따로 설명하지 않아요. 6강에서 영상이 보여 주는 링크로 확인해요.

## 꼭 지킬 것

- **Public** 저장소는 누구나 볼 수 있어요. 올리는 파일에 전화번호, 주소, 비밀번호, API 키가 없는지 올리기 전에 열어서 확인해요.
- 파일 이름은 영어 소문자 `index.html` 그대로예요(대문자·공백 주의).

::: practice
- [ ] 깃허브 계정이 있다(없으면 영상처럼 가입했다. 비밀번호는 내가 직접 입력)
- [ ] 영어 이름의 **Public** 저장소를 만들었다
- [ ] 내려받은 파일 이름을 `index.html`로 바꿨다
- [ ] 파일을 업로드하고 Commit changes까지 눌렀고, 저장소 화면에 `index.html`이 보인다
- [ ] 올린 파일에 공개하면 안 되는 정보가 없는지 열어서 확인했다
:::
