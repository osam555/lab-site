## 홈페이지는 사실 '메모장 파일'입니다

홈페이지라고 하면 뭔가 복잡한 프로그램 같죠? 놀랍게도 홈페이지의 정체는 **글자가 적힌 파일 하나**입니다. 
`index.html`이라는 이름의 파일을 인터넷 브라우저가 열어서 보여주는 것뿐이에요. 사진이나 지도도 전부 이 파일 안에 글자로 적혀 있습니다.

이 파일을 **내 컴퓨터**에서 열면 나만 볼 수 있고, **인터넷**에 올려두면 전 세계 누구나 볼 수 있습니다. 그게 전부예요!

## 홈페이지를 위한 3가지 준비물

홈페이지를 가게에 비유해 볼까요? 딱 3가지만 있으면 됩니다.

| 조각 | 역할 | 비유 | 우리가 할 일 |
|---|---|---|---|
| **파일** | 홈페이지의 내용과 모양 | **가게 인테리어** | AI(Claude)가 알아서 만들어줍니다 |
| **호스팅** | 파일을 24시간 켜진 컴퓨터에 올리는 것 | **가게 건물** | 무료 서비스를 이용할 거예요 |
| **도메인** | 사람들이 찾아올 수 있는 주소 (`mycafe.kr`) | **가게 간판·주소** | 나중에 내 주소를 달아줄 거예요 |

## 코딩 몰라도 됩니다. "바이브 코딩" 하세요!

이 강좌에서는 어려운 코드를 한 줄도 직접 쓰지 않습니다. 

대신 **클로드 데스크탑 앱의 Code(코드) 탭**에 있는 똑똑한 인공지능 비서에게 카카오톡 하듯이 한국어로 말만 하면 됩니다. 터미널(검은 명령 창)은 열지 않아도 됩니다.
> 🗣️ "가게 소개 홈페이지 만들어줘. 위에는 사진, 아래는 메뉴 넣어줘."

그러면 AI가 파일을 뚝딱 만들어줍니다. 여러분은 결과를 보고 "글자 크기 좀 키워줘", "배경색을 따뜻하게 해줘"라고 말로 고쳐나가면 됩니다. 참 쉽죠?

## 무엇을 만들까요?

결과물은 **"스마트폰에서도 예쁘게 보이는 진짜 홈페이지"**입니다. 아래 중에서 하나를 골라보세요.

| 유형 | 어떤 내용이 들어가나요? | 추천 대상 |
|---|---|---|
| **가게·매장** | 소개 / 메뉴 / 오시는 길 (지도) / 문의 | 카페, 식당, 미용실, 학원 등 |
| **개인·포트폴리오** | 소개 / 하는 일 / 작업 사진 / 연락처 | 프리랜서, 디자이너, 사진작가 |
| **소규모 회사** | 서비스 소개 / 장점 / 고객 문의 폼 | 1인 기업, 스타트업, 컨설팅 |

> 💡 **진짜로 쓸 홈페이지**를 상상하고 만들면 훨씬 재밌습니다!

## 따라하기: 종이에 그려보기

자, A4 용지를 한 장 꺼내서 세로로 놓아보세요. 위에서부터 아래로 내 홈페이지에 뭐가 들어갈지 네모 상자로 대충 그려봅니다.

```text
┌──────────────────────────────┐
│ 내 이름 또는 가게 이름         │
├──────────────────────────────┤
│                              │
│    예쁜 사진 1장 + 멋진 소개글 │  
│                              │
├──────────────────────────────┤
│ 대표 메뉴나 내 작업물 3개      │
├──────────────────────────────┤
│ 지도 (오시는 길)             │
├──────────────────────────────┤
│ 전화번호 · 인스타 주소        │
└──────────────────────────────┘
```
