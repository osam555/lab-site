## 홈페이지는 그냥 파일입니다

놀랍게도 홈페이지의 정체는 **글자로 된 파일 하나**입니다. `index.html`이라는 이름의 파일을 브라우저가 열면 그게 홈페이지입니다. 사진, 지도, 문의 폼도 전부 이 파일 안에 글자로 적혀 있습니다.

이 파일을 **내 컴퓨터에서 열면 나만** 봅니다. **인터넷의 컴퓨터에 올려두면 누구나** 봅니다. 그게 전부입니다.

## 세 조각

| 조각 | 역할 | 비유 | 이 과정에서 |
|---|---|---|---|
| **파일** (HTML/CSS) | 홈페이지의 내용과 모양 | 가게 인테리어 | Claude Code가 씁니다 |
| **호스팅** | 파일을 24시간 켜둔 컴퓨터에 올려두는 것 | 가게 건물 | Vercel, 무료 |
| **도메인** | 사람이 기억하는 주소 (`mycafe.kr`) | 가게 간판·주소 | 연 1~2만 원, 9강 |

세 조각이 이어지면 누군가 `mycafe.kr`을 입력했을 때 → 도메인이 호스팅 컴퓨터를 가리키고 → 그 컴퓨터가 파일을 보내주고 → 브라우저가 화면으로 그립니다.

## "바이브 코딩"으로 만든다는 것

파일 안의 글자(코드)를 여러분이 직접 쓰지 않습니다. **Claude Code**라는 도구에게 한국어로 "가게 소개 홈페이지 만들어줘. 위에 사진, 아래 메뉴, 맨 아래 지도"라고 말하면 파일이 만들어집니다. 여러분은 결과를 보고 "사진 더 크게", "글자 색 바꿔"라고 고쳐 나갑니다.

이 과정에서 여러분이 배우는 건 코드가 아니라:
1. 도구를 설치하고 켜는 법 (2~3강)
2. 원하는 걸 정확히 말하는 법 (4~7강)
3. 인터넷에 올리고 내 주소를 다는 법 (8~10강)

## 무엇을 만들까요?

이 과정의 결과물은 **"한 장짜리로 시작해 4~5페이지로 자라는 홈페이지"** 입니다. 아래 셋 중 하나를 고르세요. 강의의 예시는 첫 번째로 진행합니다.

| 유형 | 페이지 | 예시 |
|---|---|---|
| **가게·사업** | 소개 / 메뉴·서비스 / 오시는 길 / 문의 | 카페, 미용실, 공방, 학원 |
| **개인·프리랜서** | 소개 / 하는 일 / 작업 사례 / 연락 | 디자이너, 강사, 사진가 |
| **모임·행사** | 소개 / 일정 / 참가 신청 / 장소 | 독서 모임, 지역 행사 |

**없는 가게를 상상해도 됩니다.** 연습이니까요. 다만 실제로 쓸 것이 있으면 동기가 훨씬 강합니다.

## 따라하기: 종이에 그리기

A4 한 장을 세로로 놓고, 위에서 아래로 홈페이지 첫 화면을 네모로 그립니다.

```
┌──────────────────────────────┐
│ 가게 이름            메뉴 링크 │  ← 상단
├──────────────────────────────┤
│                              │
│    큰 사진 + 한 줄 소개        │  ← 첫인상
│      [예약하기 버튼]           │
├──────────────────────────────┤
│ 대표 메뉴 3개 (사진+이름+가격)  │
├──────────────────────────────┤
│ 오시는 길 (지도) + 영업시간     │
├──────────────────────────────┤
│ 전화 · 인스타 · 주소           │  ← 하단
└──────────────────────────────┘
```

각 네모 안에 **실제로 들어갈 글**을 적어보세요. "한 줄 소개"에는 진짜 한 줄을. "메뉴 3개"에는 진짜 이름과 가격을. 이 종이가 4강에서 Claude Code에게 보여줄 설계도입니다.

## 준비물 확인

- [ ] 노트북 (Windows 10 이상 또는 macOS)
- [ ] Claude 계정 — claude.ai에서 가입. Claude Code를 쓰려면 Pro 이상 구독 또는 API 결제가 필요합니다
- [ ] 홈페이지에 넣을 사진 3~5장 (없으면 6강에서 무료 사진을 씁니다)
- [ ] 위에서 그린 종이 한 장

## 오늘의 체크리스트
