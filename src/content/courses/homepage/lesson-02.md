## 오늘 설치할 것

| 도구 | 무엇인가 | 왜 필요한가 |
|---|---|---|
| **Claude Code 앱** | Claude Code가 들어있는 데스크탑 앱 | 홈페이지를 만들어주는 AI 도구 |
| **Git** | 파일 변경 기록·되돌리기 도구 | 망쳤을 때 되돌리고, 8강에서 인터넷에 올릴 때 |

순서대로 하나씩. **하나 끝나면 확인하고** 다음으로 넘어갑니다.

## 1. Claude Code 앱

claude.ai 에 접속해 **다운로드** 버튼을 누릅니다. 내 운영체제(Windows / Mac)에 맞는 파일이 받아집니다.

::: windows
1. 받은 설치 파일을 더블클릭
2. 설치 화면은 전부 **다음** (기본값 그대로)
3. 설치 완료 후 앱 실행
:::

::: mac
1. 받은 `.dmg` 파일을 더블클릭
2. `Claude Code.app`을 **응용 프로그램 폴더로 드래그**
3. 응용 프로그램에서 실행. "인터넷에서 다운로드한 앱입니다" 경고가 뜨면 **열기**
:::

### 로그인

앱이 처음 실행되면 로그인 화면이 나옵니다.

1. **"Claude 계정으로 로그인"** 버튼 클릭
2. 브라우저가 열리면 claude.ai 계정으로 로그인 → **"허용"** 클릭
3. 앱으로 자동 복귀. 앱 화면이 뜨면 로그인 성공

> Claude 계정이 없다면 claude.ai에서 무료 가입합니다. Claude Code를 쓰려면 **Pro 구독($20/월)** 또는 **API 결제**가 필요합니다. 과정 시작 전에 준비해두세요.

## 2. Git

Git은 파일 변경 내역을 기록하고 인터넷에 올리는 도구입니다. 8강에서 처음 씁니다.

::: windows
1. git-scm.com 에서 **Download for Windows** → 64-bit 설치 파일 받기
2. 설치 화면이 여러 개 나옵니다. **전부 Next** (기본값 그대로)
3. 설치 완료 후 시작 메뉴에서 **"Git Bash"** 를 열고:

```bash
git config --global user.name "내 이름"
git config --global user.email "내이메일@example.com"
```

아무 이름이나 괜찮고 공개되지 않습니다. 한 번만 하면 됩니다.
:::

::: mac
macOS는 8강에서 처음 `git` 명령을 입력할 때 자동으로 설치 안내가 뜹니다. 지금은 설치하지 않아도 됩니다.

미리 하고 싶다면: `Cmd + Space` → "터미널" 실행 → `git -v` 입력 → 설치 창이 뜨면 **설치**.
:::

## 설치 문제가 생기면

에러 메시지를 **그대로 복사**해서 claude.ai 채팅창에 붙여넣고 물어보세요.

> "Claude Code 앱 설치 중 이런 오류가 나왔어: [에러 메시지]. 어떻게 해?"
