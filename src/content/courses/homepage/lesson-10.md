## 문의 폼: 서버 없이

"이름, 연락처, 내용"을 받아 내 이메일로 보내주는 폼. 원래는 서버가 필요하지만, **폼 전송 서비스**를 쓰면 HTML만으로 됩니다. Formspree, Web3Forms, Getform 같은 서비스가 있고 소량은 무료입니다.

1. 서비스 가입 → 새 폼 만들기 → **폼 주소**(endpoint) 또는 **키**를 복사
2. Claude Code에게:

> contact.html에 문의 폼을 넣어줘.
> - 항목: 이름, 연락처(전화 또는 이메일), 문의 내용, [희망 날짜]
> - 전송은 [서비스 이름] 사용, 주소는 [복사한 endpoint]
> - 보내면 "접수됐습니다. 하루 안에 연락드릴게요" 표시
> - 필수 항목이 비면 빨간 안내
> - DESIGN.md 규칙대로 스타일

3. 커밋 → push → 실제 도메인에서 **직접 테스트 전송** → 내 이메일에 도착하는지 확인

스팸이 걱정되면 "폼에 [서비스]의 스팸 방지(honeypot 또는 captcha)를 켜줘".

### 폼 대신 이런 것도
- **카카오톡 채널** 링크: 가게라면 폼보다 응답률이 높습니다. "문의 페이지에 카카오톡 채널 버튼 추가해줘: [채널 링크]"
- **네이버 예약 / 캐치테이블** 링크: 예약이 핵심이면 예약 서비스 링크가 정답입니다
- **구글 폼**: 설문·신청서 형태라면 구글 폼을 만들어 링크나 삽입

## 혼자서 관리하는 루틴

### 수정할 때 (5분)
```
1. VS Code로 my-site 열기 → 터미널 → claude
2. "메뉴 페이지에서 라떼 가격을 5,500으로 바꿔줘"
3. 브라우저에서 확인
4. "커밋하고 push해줘"
5. 1분 뒤 실제 주소에서 확인
```

### 망쳤을 때
- 아직 커밋 전: `git checkout .`
- 커밋했는데 이상함: "마지막 커밋 취소해줘" (Claude가 `git revert`를 해줍니다)
- 뭐가 뭔지 모르겠음: GitHub에서 이전 버전을 볼 수 있습니다. Vercel에서도 **Deployments** 목록의 이전 배포를 **Promote**하면 즉시 그 버전으로 돌아갑니다

### 백업
이미 되어 있습니다. GitHub에 전부 있고, 노트북이 고장 나면 새 컴퓨터에서 `git clone https://github.com/내아이디/my-site`로 통째로 내려받으면 됩니다. 사진 원본만 따로 클라우드에 두세요.

### 한 달에 한 번
- 폰에서 전 페이지 한 번씩 눌러보기 (링크 깨짐, 지도, 전화)
- Search Console에서 "어떤 검색어로 들어오는지" 보기 → 그 단어를 첫 화면 소개에 넣기
- 사진 한 장 바꾸기. 살아 있는 홈페이지로 보입니다

## 자주 오는 요청 모음

앞으로 이런 것들을 하게 됩니다. 전부 Claude Code에게 한 문장이면 됩니다.

| 하고 싶은 것 | 요청 |
|---|---|
| 공지 띄우기 | "첫 화면 맨 위에 '[문구]' 공지 띠를 넣어줘. 닫기 버튼 포함" |
| 새 페이지 | "events.html을 만들어줘. 상단 메뉴에도 추가. 내용은 [..]" |
| 인스타 피드 | "인스타그램 최근 게시물 6개를 보여주는 섹션. [삽입 서비스] 사용" |
| 방문자 수 확인 | "Vercel Analytics 켜줘" 또는 "Google Analytics 태그 넣어줘: [ID]" |
| 영어 페이지 | "index.html의 영어 버전 en/index.html을 만들고 언어 전환 링크 추가" |
| 속도 점검 | "PageSpeed Insights 결과야 [붙여넣기]. 빨간 항목 고쳐줘" |
