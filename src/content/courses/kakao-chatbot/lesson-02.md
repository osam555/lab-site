## 준비물

| 준비물 | 비고 |
|---|---|
| 안드로이드 공기계 1대 | 상시 충전·와이파이. 아이폰은 봇 기기가 될 수 없어요 |
| 부계정 | 본계정과 다른 전화번호. 인증 문자만 받을 수 있으면 돼요 |
| 메신저봇R 앱 | 알림을 받아 스크립트를 실행하고 알림 답장을 보내는 안드로이드 앱 |
| 클라우드 계정 | API를 올릴 곳. 이 과정은 Vercel을 예로 들어요([Vercel 기초](/basics/vercel-basics)) |
| AI 모델 키 | 모델 서비스의 API 키. 서버 환경변수에 **내가 직접** 등록해요 |
| 클로드 데스크탑 Code 탭 | 클로드에게 시켜 만드는 기본 도구 |

## 사람이 직접 하는 것

클로드는 폰을 대신 만져 주지 못해요. 아래는 **내 손으로** 해요.

1. 공기계에 카카오톡을 설치하고 **부계정**으로 로그인해요. 인증 번호와 비밀번호는 내가 직접 입력하고, 채팅에 붙여넣지 않아요([안전·비용·계정](/basics/vibe-safety-money)).
2. 부계정을 시험 방에 넣어요. 처음엔 **나(본계정)와 부계정 둘만 있는 방**을 만들어요.
3. 메신저봇R을 설치하고 **알림 접근 권한**을 허용해요. 카톡 설정에서 **알림에 메시지 내용 표시**를 켜요.
4. 메신저봇R과 카톡이 **배터리 제한 목록**에 들어 있지 않게 해요. 절전에 걸리면 알림이 끊겨요.
5. 시험 방의 알림이 켜져 있는지 확인해요. 그 방 화면을 폰에서 열어 둔 채로는 알림이 생기지 않으니, 시험할 때는 폰 화면에서 방을 닫아 둬요.

기기와 앱 버전마다 메뉴 이름이 달라요. 막히면 메신저봇R의 공개 문서와 폰 제조사 안내를 먼저 봐요.

## 클로드에게 맡길 수 있는 것

화면을 만지는 일은 못 해도 **무엇을 어떤 순서로 점검할지**는 정리해 줘요.

> 안드로이드 공기계에 카톡 부계정과 메신저봇R을 설치해서 알림 답장 봇을 만들려고 해. `chatbot/phone-checklist.md`에 내가 폰에서 직접 눌러야 할 항목을 순서대로 체크리스트로 써줘. 알림 접근, 알림 내용 표시, 배터리 제한, 방 무음, 방 화면 닫기를 꼭 넣고, 항목마다 "안 되면 어디를 볼지" 한 줄을 붙여줘. 내 계정 정보나 비밀번호는 묻지 마.

터미널로도 할 수 있어요. 결과 파일을 폰 옆에 두고 하나씩 체크해요.

## 이 강에서는 아직 답하지 않아요

봇이 답하는 것은 3강이에요. 오늘은 **폰이 알림을 받는 환경**까지만 만들어요. 메신저봇R에서 시험 방의 알림이 들어오는지 확인해요.

::: practice
- [ ] 공기계에 부계정으로 로그인했고, 같은 계정이 다른 기기에 로그인되어 있지 않다
- [ ] 메신저봇R에 알림 접근을 허용하고 카톡 알림 내용 표시를 켰다
- [ ] 배터리 제한에서 메신저봇R·카톡을 제외했다
- [ ] 나·부계정 둘만 있는 시험 방을 만들었고 알림이 오는 것을 폰에서 확인했다
:::

## 오늘의 체크리스트

- [ ] 사람이 직접 해야 하는 일(로그인·권한 허용)과 클로드가 도울 일을 구분했다
- [ ] 비밀번호·인증 번호를 채팅에 쓰지 않았다
- [ ] 폰 충전기와 와이파이를 상시 연결해 두었다
