## 이 과정에서 만드는 것

내가 운영하는 카톡 오픈채팅·단톡방에서 **호출어로 부르면 내 자료를 바탕으로 짧게 답하고, 정해진 시각에 안내를 올리는 챗봇**이에요. 클로드 데스크탑의 Code 탭에게 단계를 하나씩 시키고, 사람은 폰 설정, 지식 확인, 승인, 선 정하기를 해요. 터미널로도 할 수 있어요 라는 보조 설명이 강마다 붙어 있어요.

카카오에는 오픈채팅·단톡방용 공식 봇 API가 없어서, 이 과정은 **알림을 읽고 알림 답장을 보내는 비공식 방식**을 써요. 약관·계정 제한 위험이 있고 제재를 막을 수 없어요. 1강과 12강에서 이 위험을 다루고, 위험은 내가 판단해서 감수해요.

## 전체 흐름

**1부 · 준비**
1. **1강 왜 챗봇인가**: 공식 봇 API가 없는 이유와 전체 구조, 부계정을 쓰는 이유를 이해해요. (35분)
2. **2강 준비물과 공기계 설정**: 공기계·부계정·메신저봇R·알림 접근, 사람이 직접 하는 것. (40분)
3. **3강 첫 응답**: 호출어로만 답하기, 쿨다운·하루 한도, 실패하면 침묵. (45분)

**2부 · 지식**
4. **4강 지식 팩 만들기**: 내 자료를 300~800자 조각으로 나누고 빌드·검사해요. (45분)
5. **5강 /ask API 만들기**: 검색·모델·후처리, Vercel 배포, 토큰, 평문 규칙. (50분)
6. **6강 정정표**: 확정한 답을 최우선으로 두고 틀린 답을 고치는 흐름. (40분)
7. **7강 평가**: 질문 목록으로 검색 공백을 찾고 줄여요. (40분)

**3부 · 운영**
8. **8강 발송 대기열과 발송 시각**: 루틴 발송, 방 번호로 방 식별, 폰 재시작 뒤 대처. (50분)
9. **9강 방에서 가르치기**: 기억 명령 → 승인 → 지식 반영. (40분)
10. **10강 방 대화 수집으로 할 일·일정**: 동의·범위·본문 비저장, 개인 위키 연결. (40분)
11. **11강 끊김 감시·자동 업데이트·백업**: 하트비트, 서명 업데이트 개념, 키 백업. (45분)
12. **12강 지켜야 할 선**: 내 방·동의·광고 표시·개인정보·비용 규칙표. (35분)

## 실습 결과물

- 시험 방에서 호출어로만 답하는 봇(공기계 + 메신저봇R)
- 내 자료로 만든 지식 팩과 정정표, 평가 질문 목록과 공백 보고서
- Vercel에 올라간 /ask API(키는 내가 직접 등록)
- 시험 방에 올라간 예약 발송 1건
- 방에서 가르치기 승인 흐름, 끊김 알림
- 내 방의 규칙표(`rules.md`)

## 준비물

- 안드로이드 공기계(상시 충전·와이파이)와 **본계정이 아닌 부계정**(다른 전화번호)
- 메신저봇R 앱, 클로드 데스크탑(Code 탭) 또는 터미널의 Claude Code
- Vercel 계정, AI 모델 서비스의 API 키(서버에 내가 직접 등록)
- 내 자료(안내문·자주 묻는 질문 등)와 내가 운영하는 방
- 선행 권장: [Vercel 기초](/basics/vercel-basics), [안전·비용·계정](/basics/vibe-safety-money)

## 끝나면 할 수 있는 것

- 카톡 챗봇이 공기계·메신저봇R·클라우드 API·지식 팩으로 이루어진다는 구조를 설명해요.
- 내 자료를 조각으로 나누고, 평가로 공백을 찾고, 틀린 답을 정정표로 고쳐요.
- 정해진 시각 발송, 방에서 가르치기, 끊김 감시를 운영해요.
- 동의·광고 표시·개인정보·비용의 선을 내 규칙표로 정하고, 멈추는 방법을 알아요.
