## 홈페이지 vs 랜딩페이지

| | 홈페이지 | 랜딩페이지 |
|---|---|---|
| **목적** | 정보 전달, 브랜드 소개 | **특정 행동 유도** (구매·신청·다운로드) |
| **페이지 수** | 여러 페이지 | 보통 1페이지 |
| **내비게이션** | 메뉴 있음 | 없거나 최소화 |
| **성공 기준** | 방문자 수, 체류 시간 | **전환율** (행동한 사람 ÷ 전체 방문) |

랜딩페이지는 **딱 하나의 행동**을 시키는 페이지입니다. "이것저것 보여주자"가 아니라 "이 버튼을 누르게 하자"입니다.

## 전환율이란

100명이 방문해서 3명이 신청하면 전환율 **3%**. 잘 만든 랜딩페이지는 5~15%. 여기서 1%만 올려도 매출이 바뀝니다.

## 랜딩페이지의 7가지 블록

모든 유형에 공통된 뼈대입니다. 위에서 아래로:

| 순서 | 블록 | 역할 |
|---|---|---|
| 1 | **히어로** | 헤드라인 + CTA 버튼. 3초 안에 "뭔지" 전달 |
| 2 | **핵심 장점** | 왜 좋은지 3~4개 (아이콘 + 짧은 설명) |
| 3 | **시연/증거** | 스크린샷, 영상, 데모 |
| 4 | **사회적 증거** | 사용자 수, 후기, 언론 로고 |
| 5 | **가격/조건** | 가격표 또는 혜택 |
| 6 | **FAQ** | 망설이는 이유를 미리 해소 |
| 7 | **마지막 CTA** | 같은 버튼 한 번 더 |

## 이 과정에서 만드는 사례

| 강 | 유형 | 예시 |
|---|---|---|
| 3강 | 제품·서비스 출시 | SaaS 도구, 핸드메이드 제품, 구독 서비스 |
| 4강 | 강좌·워크숍 모집 | 온라인 강의, 부트캠프, 클래스 |
| 5강 | 앱 다운로드·사전예약 | 모바일 앱, 얼리버드, 크라우드펀딩 |
| 6강 | 이벤트·프로모션 | 세미나, 할인 행사, 뉴스레터 구독 |
| 7강 | 포트폴리오·개인 브랜딩 | 프리랜서, 컨설턴트, 작가 |
| 8강 | CTA 최적화와 배포 | 전환율 개선, 도메인 연결, 분석 |
