## Claude Code 설치 (5분)

이미 설치한 사람은 건너뛰세요.

### Windows

1. [nodejs.org](https://nodejs.org) → LTS 버전 다운로드 → 설치
2. 시작 메뉴 → "PowerShell" 검색 → 열기
3. `node -v` 입력 → 버전 숫자가 나오면 성공
4. Claude Code 데스크탑 앱: [claude.ai/download](https://claude.ai/download)에서 다운로드 → 설치

### macOS

1. [nodejs.org](https://nodejs.org) → LTS 버전 다운로드 → 설치
2. 터미널(Spotlight → "터미널") → `node -v` → 버전 확인
3. Claude Code 데스크탑 앱: [claude.ai/download](https://claude.ai/download)에서 다운로드 → 설치

## 프로젝트 폴더 만들기

바탕화면에 `my-landing` 폴더를 만들고, Claude Code 앱에서 **Open Folder** → 이 폴더를 선택합니다.

## 유형별 준비물 정리

아래에서 내 유형을 찾아 준비물을 `my-landing/` 폴더에 넣고, 메모를 정리해두세요.

### 🚀 제품·서비스 출시

| 준비물 | 설명 | 파일명 예시 |
|---|---|---|
| 제품 이미지 | 1~3장 | `images/product.jpg` |
| 로고 | | `images/logo.png` |
| 시연 영상 | 선택 (YouTube 링크도 OK) | 링크 메모 |

```
제품/서비스 이름:
헤드라인: (한 문장 핵심 가치. 예: "30초면 명함이 홈페이지가 됩니다")
서브 헤드라인: (보충 1줄)
핵심 장점 3가지:
  1.
  2.
  3.
가격 또는 조건:
CTA 버튼 문구: (예: "지금 시작하기")
CTA 링크: (구매 URL, 카카오톡 등)
사회적 증거: (사용자 수, 후기, 수상 등)
```


## 사진 파일 규칙

1. **이름**: 영어 소문자 + 하이픈. `제품사진.jpg` ❌ → `product.jpg` ✅
2. **크기**: 가로 1600px 이하
3. **폴더**: `my-landing/images/` 안에 넣기

## 오늘의 체크리스트

- [ ] Claude Code 앱이 설치되어 있다
- [ ] `my-landing` 폴더가 앱에 연결되어 있다

- [ ] 이미지를 `images/` 폴더에 넣었다
