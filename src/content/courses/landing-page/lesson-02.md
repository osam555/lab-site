## Claude 데스크탑 앱 설치 (5분)

이미 설치한 사람은 건너뛰세요.

1. [claude.ai/download](https://claude.ai/download)에서 내 컴퓨터(Windows 또는 macOS)에 맞는 데스크탑 앱을 다운로드해 설치합니다. 설치 화면에서는 기본값대로 **다음**만 누르면 됩니다.
2. 앱을 열고 **Claude 계정으로 로그인**합니다.
3. 앱 위쪽(또는 옆)의 **Chat · Cowork · Code** 탭 중 **Code** 탭을 누릅니다.

## 프로젝트 폴더 만들고 연결하기

1. 바탕화면에 `my-landing` 폴더를 만듭니다.
2. Code 탭의 폴더 선택 버튼(**Open Folder**)을 눌러 이 폴더를 고릅니다. 클로드는 이 폴더 안에서만 일합니다.
3. 입력창에 "안녕! 이 폴더에 뭐가 있어?"라고 보내 보세요. 권한 요청이 뜨면 내용을 읽고 수락하면 됩니다. 폴더가 비어 있다고 답하면 연결 성공입니다.

### 터미널로도 할 수 있어요

앞 단계의 Node.js 설치와 터미널 확인, 그리고 터미널에서 쓰는 CLI 방식입니다.

#### Windows

1. [nodejs.org](https://nodejs.org) → LTS 버전 다운로드 → 설치
2. 시작 메뉴 → "PowerShell" 검색 → 열기
3. `node -v` 입력 → 버전 숫자가 나오면 성공
4. Claude Code 데스크탑 앱: [claude.ai/download](https://claude.ai/download)에서 다운로드 → 설치

#### macOS

1. [nodejs.org](https://nodejs.org) → LTS 버전 다운로드 → 설치
2. 터미널(Spotlight → "터미널") → `node -v` → 버전 확인
3. Claude Code 데스크탑 앱: [claude.ai/download](https://claude.ai/download)에서 다운로드 → 설치

터미널에서 Claude Code를 쓰려면(CLI), 프로젝트 폴더 안에서 `claude`를 실행합니다:

```bash
npm install -g @anthropic-ai/claude-code
cd ~/Desktop/my-landing
claude
```

## 유형별 준비물 정리

> 🌱 처음이라면 1강 표의 **가장 쉬운 사례**(뉴스레터 구독, 6강 사례 1)부터 만들어도 됩니다. 준비물이 가장 적습니다.

아래에서 내 유형을 찾아 준비물을 `my-landing/` 폴더에 넣고, 메모를 정리해두세요.

---

### 🚀 제품·서비스 출시

| 준비물 | 설명 | 파일명 예시 |
|---|---|---|
| 제품 이미지 | 1~3장 | `images/product.jpg` |
| 로고 | | `images/logo.png` |
| 시연 영상 | 선택 (YouTube 링크도 OK) | 링크 메모 |

```
제품/서비스 이름:
헤드라인: (한 문장 핵심 가치. 예: "30초면 명함이 홈페이지가 됩니다")
서브 헤드라인: (보충 1줄)
핵심 장점 3가지:
  1.
  2.
  3.
가격 또는 조건:
CTA 버튼 문구: (예: "지금 시작하기")
CTA 링크: (구매 URL, 카카오톡 등)
사회적 증거: (사용자 수, 후기, 수상 등)
```

---

### 📚 강좌·워크숍 모집

| 준비물 | 설명 | 파일명 예시 |
|---|---|---|
| 강사 사진 | 1장 | `images/instructor.jpg` |
| 강좌 대표 이미지 | 1장 | `images/course.jpg` |
| 수강생 후기 | 선택 | `images/review-1.jpg` |

```
강좌 이름:
한 줄 소개:
수강 대상: (예: "코딩 모르는 직장인·자영업자")
강사: 이름 / 경력 한 줄
커리큘럼:
  1주차:
  2주차:
  3주차:
수강 후 결과:
수강료: (얼리버드 / 정가)
모집 기간·인원:
신청 방법: (URL, 카톡 등)
수강생 후기 2~3개:
FAQ 3개:
```

### 🎉 이벤트·프로모션·뉴스레터

|---|---|---|

### 💼 포트폴리오·개인 브랜딩


## 사진 파일 규칙

1. **이름**: 영어 소문자 + 하이픈. `제품사진.jpg` ❌ → `product.jpg` ✅
2. **크기**: 가로 1600px 이하
3. **폴더**: `my-landing/images/` 안에 넣기
