## 다섯 단계

네이버 블로그 글 한 편은 이렇게 만들어집니다.

```
① 키워드 발굴  →  ② 리서치·초안  →  ③ 이미지·제목·태그  →  ④ 에디터 입력  →  ⑤ 발행·관리
   키워드 도구        Claude Code         Claude Code          브라우저 자동화       사람
```

| 단계 | 하는 일 | 도구 | 사람이 하는 것 |
|---|---|---|---|
| ① 키워드 | 검색량·경쟁도로 쓸 주제 30개 | 네이버 키워드 도구 + Claude | 내 분야에 맞는지 판단 |
| ② 초안 | 출처 붙은 리서치 → 1,500~2,500자 초안 | Claude Code | **내 경험 채우기**, 사실 확인 |
| ③ 준비물 | 이미지, 제목 3안, 태그, 요약 | Claude Code | 사진 고르기, 제목 고르기 |
| ④ 입력 | 스마트에디터에 제목·본문·이미지·태그 채우고 **임시저장** | 브라우저 자동화 | 화면 확인 |
| ⑤ 발행 | 발행 버튼, 이후 통계 확인 | — | **발행 클릭**, 댓글 응대 |

핵심 한 줄: **글 만드는 노동은 자동화하고, 발행이라는 판단은 사람이 합니다.** 이유는 아래에 있습니다.

> **용어 풀이** 저품질 = 네이버 검색에서 내 블로그 글의 노출이 크게 줄어드는 상태(공식 용어는 아니고 블로거들이 쓰는 말), 키워드 = 사람들이 검색창에 치는 말, 스마트에디터 = 네이버 블로그 글쓰기 화면입니다.

## 네이버가 글을 고르는 방식 (알아야 할 만큼만)

네이버 검색은 대략 두 가지를 봅니다.

1. **블로그 자체의 신뢰도** — 한 분야를 꾸준히 쓰는가(주제 일관성), 방문자가 오래 머무는가, 실제 경험이 담겼는가
2. **글 하나의 품질** — 검색 의도에 맞는 답을 주는가, 사진·구조가 읽기 좋은가, 복붙이 아닌가

여기서 자동화의 경계가 나옵니다.

## 하면 안 되는 자동화

| 이렇게 하면 | 결과 |
|---|---|
| 하루 5편씩 자동 발행 | 기계적 패턴으로 분류 → 검색 노출 제외("저품질") |
| AI 초안을 손 안 대고 그대로 | 비슷한 글이 검색에 많음 → 경험 없는 글로 판단 |
| 여러 분야를 섞어 발행 | 블로그 주제 일관성 무너짐 |
| 로그인 세션을 봇으로 돌려 발행까지 자동 클릭 | 계정 이용 제한 위험 |

그래서 이 과정은 **주 3편, 발행은 사람이, 초안엔 반드시 내 경험 한 단락**을 원칙으로 합니다. 자동화는 "30분 걸리던 준비를 5분으로" 줄이는 데 쓰고, 나머지 25분을 내 경험을 쓰는 데 씁니다.

## 따라하기: 분야와 독자 정하기

### 1. 분야 하나
네이버 블로그는 **한 분야**를 고정해야 신뢰도가 쌓입니다. 이미 블로그가 있다면 가장 반응 좋았던 카테고리, 없다면 내가 실제로 경험을 계속 쌓는 것.

> 예: 캠핑 장비 / 부산 맛집 / 초등 자녀 교육 / 소형 카페 창업 / 인테리어 셀프 시공

### 2. 독자 한 사람
> "주말마다 아이 둘 데리고 캠핑 가는데, 장비 살 때마다 뭐가 맞는지 모르는 40대 아빠"

### 3. 내가 줄 수 있는 것
검색해서 나오는 정보가 아니라 **내가 해봐서 아는 것**. 이게 AI 초안과 내 글의 차이를 만듭니다. 세 줄만 적으세요.

`blog-plan.md`에 세 항목을 적어둡니다. 2강에서 프로젝트 폴더에 넣습니다. 메모장 등에 아래 틀을 붙여 넣고 채우면 됩니다.

```
# blog-plan
분야: 
독자 한 사람: 
내가 줄 수 있는 것(내가 해봐서 아는 것 3가지):
1.
2.
3.
```
