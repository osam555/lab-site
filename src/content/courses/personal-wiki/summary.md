## 이 과정에서 만드는 것

흩어진 메모·자료를 **폴더와 마크다운 파일**로 쌓아 두고, 클로드가 읽고 정리하고 답해 주는 **나만의 지식 베이스(개인 위키)** 를 직접 만듭니다. 클로드 데스크탑 앱의 **Code 탭**이 기본 도구이고, 터미널 방법은 '터미널로도 할 수 있어요'에 접어 두었습니다. 벡터 DB·검색 서버 같은 기술은 쓰지 않습니다.

## 전체 흐름 (강별 한 줄)

| 부 | 강 | 한 줄 요약 |
|---|---|---|
| 1부 필요성 | 1 개인 위키가 뭐고 왜 필요한가 | 검색 대신 쌓기, AI가 읽는 지식 창고, 주제 정하기 |
| 2부 구축 | 2 폴더 만들기와 규칙 파일 | raw·wiki·index.md·CLAUDE.md 뼈대 |
| | 3 첫 자료 넣기 | 원본은 raw에, 클로드가 정제해 wiki 페이지로 |
| | 4 페이지 규칙 | frontmatter·updated·위키링크·index 연결 |
| | 5 점검과 정리 | 깨진 링크·고아 페이지·오래된 페이지, lint 만들기 |
| | 6 깃으로 백업하고 되돌리기 | 커밋으로 안전망 |
| 3부 활용 | 7 질문하고 답 받기 | 위키를 근거로 출처와 함께 답 받기 |
| | 8 일정 관리 | 월별 일정 페이지, 반복 일정, 캘린더에 올릴 목록 |
| | 9 업무 관리 | 프로젝트 페이지, 로그, 주간 요약, 월 증류 |
| | 10 할 일 관리 | 오늘·이번 주·보류·완료, 결재함 |
| | 11 관제탑으로 쓰기 | 위 셋을 대시보드 한 장으로, 아침 브리핑 |
| | 12 꺼내 쓰기 | 챗봇 지식 팩(정정표 포함), 다른 과정의 원고 창고 |

## 실습 결과물

- `my-wiki` 폴더: `CLAUDE.md`, `raw/`, `wiki/index.md`, 정리 페이지 여러 개
- `scripts/lint_wiki.py` 점검 도구와 깃 커밋 이력
- 일정·프로젝트·할 일·결재함 페이지와 `wiki/dashboard.md`
- `wiki/bot/faq.md`, 정정표, 지식 팩 파일(`bot-pack/knowledge.json`)

## 준비물

| 것 | 설명 |
|---|---|
| 클로드 데스크탑 앱(Code 탭) | 모든 실습의 기본 도구 |
| 위키로 만들 자료 | 강의 노트·독서 기록·고객 문의 정리 등 한 주제 |
| 깃 | 6강에서 설치·사용 (클로드가 안내) |
| 시간 | 강마다 30~40분, 하루 5분 기록 습관은 선택 |

## 끝나면 할 수 있는 것

- 자료를 원본과 정리본으로 나눠 쌓고, 규칙 파일로 클로드가 같은 방식으로 일하게 할 수 있다
- 위키를 근거로 출처가 달린 답을 받고, 없는 내용은 '없음'이라고 답하게 할 수 있다
- lint로 위키 상태를 점검하고, 깃으로 되돌릴 수 있다
- 일정·업무·할 일을 위키에 두고 오늘 브리핑과 주간 요약을 받을 수 있다
- 위키에서 챗봇 지식 팩을 만들고, 정정표로 틀린 답을 고칠 수 있다
