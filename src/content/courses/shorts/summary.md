## 이 과정에서 만드는 것

주제 한 줄만 넣으면 80~100초짜리 9:16 지식 쇼츠(대본·영상 클립·나레이션·BGM·자막·썸네일)가 만들어지는 **나만의 쇼츠 공장**입니다. Claude Code(클로드 데스크탑의 Code 탭)에게 다섯 단계를 순서대로 시키고, 사람이 확인할 지점(⏸)에서 직접 검수하는 방식입니다. 마지막에는 이 전체 순서를 스킬 하나로 저장합니다.

## 전체 흐름

1. **1강 파이프라인 이해**: 다섯 단계와 도구를 익히고, 소재 분야·레퍼런스 채널·첫 주제 3개를 정합니다.
2. **2강 도구 세팅**: ffmpeg 설치, API 키 보관(.env), 프로젝트 폴더와 CLAUDE.md 규칙 파일, 첫 커밋.
3. **3강 레퍼런스 분석과 대본**: 레퍼런스를 분석해 4초 × 20~25컷 대본을 `script.json`으로 확정합니다.
4. **4강 비주얼 프롬프트**: 스타일 앵커로 모든 컷의 영문 프롬프트를 한 영상처럼 일관되게 다듬습니다.
5. **5강 Google Flow 클립**: 손으로 세 컷 → 반자동으로 나머지 컷 생성·수집 → 격자 이미지로 검수합니다.
6. **6강 더빙**: Typecast(기본)로 컷별 나레이션을 만들고 길이를 맞춘 뒤 이어서 들어봅니다.
7. **7강 ffmpeg 합성**: 클립+음성+BGM+자막을 합쳐 `final.mp4`, 썸네일, 제목·설명 초안을 만듭니다.
8. **8강 스킬 저장과 운영**: 전체를 스킬로 저장, 두 번째 영상 제작, 비공개 업로드 확인, 주간 루틴.

## 실습 결과물

- `shorts-factory/` 프로젝트 폴더와 CLAUDE.md
- 첫 영상의 `script.json`·`script.md`, `prompts/`, `clips/`, `voice/`
- `output/final.mp4`(세로 1080×1920), `thumb.jpg`, `meta.md`
- 스크립트(`dub-typecast.py`, `assemble.py`)와 `.claude/skills/` 아래 쇼츠 제작 스킬
- 두 번째 영상(주제 한 줄로 제작)과 주간 운영 표

## 준비물

- 클로드 데스크탑 앱(Code 탭) 또는 터미널의 Claude Code
- Google 계정 + Gemini Pro 구독(Google Flow 크레딧). 없으면 무료 크레딧 범위에서 연습
- Typecast 계정(기본) 또는 ElevenLabs 계정(선택), 유튜브 채널(8강 업로드용)
- 월 크레딧 약 250(영상 1편)과 음성 글자 수 한도 확인(1강)
- 유튜브 오디오 라이브러리 BGM 2~3곡, 자막용 Bold 글꼴 1개

## 끝나면 할 수 있는 것

- 쇼츠 한 편이 어떤 단계를 거쳐 만들어지는지 설명하고, 단계마다 사람이 확인할 곳을 압니다.
- 레퍼런스를 분석해 4초 호흡의 대본을 쓰고, 사실 확인까지 마칩니다.
- 크레딧을 아끼는 순서(대본 확정 → 클립 → 더빙 → 합성)로 영상을 만듭니다.
- 문제가 생긴 컷만 골라 다시 만듭니다.
- 비공개로 올려 직접 확인한 뒤 공개하고, 주 1편 루틴으로 운영합니다.
