## 콘텐츠는 있는데 올리는 게 일입니다

블로그 글 한 편, 쇼츠 한 편을 만들면 그걸 인스타·스레드·X·링크드인·카카오 채널에 각각 다시 써서 올려야 합니다. 채널마다 글자 수, 톤, 해시태그, 이미지 비율이 다르니 한 편에 한 시간이 갑니다. 이 과정은 그 한 시간을 **5분 + 확인**으로 줄입니다.

```
원본 (블로그 글 / 영상 / 메모)
   ↓ ① 채널별 변환          Claude Code + 규칙 파일
   ↓ ② 이미지 카드 생성       HTML 템플릿 → 스크린샷
   ↓ ③ 예약 발행            스케줄러 API
   ↓ ④ 성과 수집·되먹임      주간 리포트 → 규칙 파일 갱신
```

## 채널별 현실

자동화가 어디까지 되는지는 **채널의 API 정책**이 정합니다. 2025년 기준 대략:

| 채널 | 글자 | 이미지 | 자동 발행 | 비고 |
|---|---|---|---|---|
| **스레드(Threads)** | 500자 | 1:1, 4:5 | ○ Threads API 직접 | 텍스트 중심, 대화체 |
| **X** | 280자(유료 확장) | 16:9, 1:1 | △ API 유료 티어 | 스레드(연속 글) 유리 |
| **인스타그램** | 캡션 2,200자 | 1:1, 4:5, 캐러셀 | △ 비즈니스 계정 + Graph API | 이미지가 전부 |
| **링크드인** | 3,000자 | 1.91:1, 1:1 | ○ 공식 API (앱 심사) | 격식체, 인사이트 |
| **카카오톡 채널** | 제한 적음 | 카드형 | △ 관리자센터 예약 | 국내 고객 알림 |
| **Facebook 페이지** | 63,206자 | 1.91:1, 1:1 | ○ Graph API (Page Access Token) | 브랜드 페이지 전용 |
| **Facebook 개인** | 63,206자 | 1.91:1, 1:1 | ✕ (앱 리뷰 필요) | Aside 브라우저로 반자동 |
| **네이버 블로그** | — | — | ✕ | [네이버 블로그 강좌](/lectures/naver-blog) 참조 |

정책은 자주 바뀝니다. 이 과정은 **스케줄러 서비스** 하나에 채널을 연결하는 방법(2~7강)을 먼저 다루고, 8강에서 Facebook 페이지(Graph API)와 Threads(Threads API)를 스케줄러 없이 직접 연동하는 방법을 추가합니다.

## 스케줄러 고르기

| 스케줄러 | 특징 | 비용 |
|---|---|---|
| **Postiz** (오픈소스) | 셀프호스팅 가능, API 제공, 주요 채널 지원 | 무료(셀프) / 유료(클라우드) |
| **Buffer** | 가장 익숙, API는 제한적 | 무료 3채널 / 유료 |
| **Typefully** | X·스레드·링크드인 특화, API 좋음 | 무료 / 유료 |

이 과정은 **API가 있고 채널 폭이 넓은 것**을 기준으로 설명합니다. 2강에서 하나를 골라 연결하고, 없는 채널은 "복사 도우미"로 반자동 처리합니다.

## 자동화하지 않는 것

- **원본 만들기**: 이 과정은 변환·배포만. 원본은 블로그·쇼츠 강좌에서
- **답글·DM**: 사람이 합니다. 자동 답글은 계정 제재 사유
- **팔로우·좋아요 자동화**: 하지 않습니다
- **발행 최종 확인**: 예약 전 사람이 한 번 봅니다 (체크포인트)

## 따라하기: 채널과 목표 정하기

`sns-plan.md`에:

1. **원본 소스**: 무엇을 배포하나 (예: 네이버 블로그 주 3편 + 쇼츠 주 1편)
2. **채널 3~5개**: 독자가 있는 곳만. 다섯 개 다 할 필요 없습니다
3. **채널별 목적**: 스레드=대화·유입, 인스타=브랜드·저장, 링크드인=신뢰, X=속보, 카카오=고객 알림
4. **주간 목표 지표 하나**: 팔로워보다 **링크 클릭** 또는 **저장/공유**를 권합니다
