## 이 과정에서 만드는 것

원본 글·영상 하나를 스레드·X·인스타그램·링크드인·카카오 채널 등 **여러 채널 형식으로 바꾸고, 이미지 카드를 만들고, 예약 발행하고, 성과를 모아 규칙을 개선하는 "SNS 배포 공장"**입니다. Claude Code(클로드 데스크탑의 Code 탭)가 변환·카드·예약 등록을 맡고, 사람은 후크 선택·카드 검수·예약 승인을 직접 합니다. 답글·DM은 사람이 손으로 합니다.

## 전체 흐름

1. **1강 하나를 만들어 다섯 곳에**: 4단계 파이프라인, 채널별 자동화 현실, 내 채널 3~5개와 주간 지표를 정합니다.
2. **2강 세팅**: 폴더, 스케줄러 연결, API 키 보관(.env), VOICE.md·CLAUDE.md, 초안 연결 테스트.
3. **3강 채널별 변환**: `channels.json` 규칙으로 원본을 채널별 `variants.json`으로 바꾸고 후크를 직접 고릅니다.
4. **4강 이미지 카드**: HTML 템플릿 하나로 채널별 비율의 카드 이미지를 자동 생성하고 눈으로 검수합니다.
5. **5강 예약 발행**: 시간표를 짜고, 표를 확인한 뒤 "예약해"로 등록. API 없는 채널은 복사 도우미로.
6. **6강 성과 수집과 되먹임**: 숫자를 모아 리포트를 만들고, 4주 뒤 규칙 파일을 데이터로 고칩니다.
7. **7강 스킬 저장과 주간 운영**: "이 글 배포해줘" 한 줄 스킬, 체크포인트 3곳, 주간 루틴.
8. **8강 (선택) Facebook·Threads 직접 API**: 스케줄러 없이 `--draft` 확인 후 직접 발행.

## 실습 결과물

- `sns-factory/` 폴더, `CLAUDE.md`, `VOICE.md`, `channels.json`
- 첫 원본의 `variants.json`·`variants.md`, `cards/` 이미지, `schedule.json`
- 스케줄러 캘린더에 올라간 예약 글, 첫 `report.md`
- 카드 템플릿(`quote.html`, `carousel.html`)과 `render-cards.py`, `clip.py`
- `.claude/skills/` 아래 SNS 배포 스킬

## 준비물

- 클로드 데스크탑 앱(Code 탭) 또는 터미널의 Claude Code
- 운영할 SNS 계정 3~5개(인스타는 비즈니스/크리에이터 계정), 스케줄러 계정(Postiz·Buffer·Typefully 중 하나)
- 배포할 원본 글 1~2편(블로그 글·영상 대본), 내가 쓴 글 샘플 몇 개(VOICE.md용)
- 브랜드 색 3가지와 핸들(@아이디)
- 8강(선택)은 Meta for Developers 계정

## 끝나면 할 수 있는 것

- 원본 하나를 채널마다 다른 말투·길이·비율로 바꿔 한 번에 준비합니다.
- 이미지 카드를 템플릿으로 몇 분 안에 만듭니다.
- 표를 확인한 뒤 채널별 최적 시각에 예약하고, 발행 결과를 직접 확인합니다.
- 성과 숫자로 후크·시간·형식 규칙을 다듬는 월 1회 순환을 돌립니다.
- 자동화하지 않을 것(답글·팔로우·즉시 발행)을 구분해 계정을 안전하게 운영합니다.
