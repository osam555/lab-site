## 만든 사람은 자기 서비스를 못 봅니다

여러분은 어디를 눌러야 하는지 알고, 어떤 순서로 써야 하는지 압니다. 처음 온 사람은 모릅니다. 그 사람이 3초 안에 헤매는 지점을 여러분은 절대 못 찾습니다. **직접 보여줘야만** 보입니다.

## 따라하기 1: 3명 고르기

- 6강에서 정한 "한 사람"에 가까운 사람 1명 (진짜 사용자)
- 편하게 솔직할 수 있는 지인 1명
- 여러분 서비스에 관심 없는 사람 1명 (가장 냉정한 피드백)

거창하게 부탁할 필요 없습니다. "5분만 이거 써보고 뭐가 헷갈리는지 말해줘."

## 따라하기 2: 관찰하기 — 설명하지 않기

가장 중요한 규칙: **옆에서 설명하지 마세요.** 링크만 보내고 지켜봅니다. 화상이면 화면 공유를 부탁하세요.

관찰 노트에 적을 것:

| 시간 | 무엇을 했나 | 표정/말 |
|---|---|---|
| 0:05 | 첫 화면에서 스크롤만 함 | "뭘 하라는 거지?" |
| 0:40 | 재료 입력 후 Enter 누름 (버튼 있는 줄 모름) | — |
| 1:20 | 추천 결과 나오자 "오" | 웃음 |
| 2:00 | 저장 눌렀는데 로그인 화면으로 가자 이탈 | "귀찮네" |

**설명하고 싶은 충동**이 올라올 때가 바로 서비스가 설명하지 못하는 지점입니다. 그 순간을 적으세요.

끝나면 세 가지만 묻습니다.
1. 이게 뭐 하는 서비스 같아요? (한 줄로)
2. 제일 헷갈린 데는?
3. 다시 쓸 것 같아요? 왜?

## 우선순위 판단

```
              비용 작음        비용 큼
심각도 높음   ★ 지금 당장       이번 주 안에
심각도 낮음   짬 날 때          안 함 (TODO에 기록만)
```

"안 함"을 정하는 게 중요합니다. 피드백을 전부 반영하면 서비스가 산으로 갑니다. 6강의 "한 사람"에게 중요한 것만 고릅니다.

## 흔한 피드백과 처방

| 피드백 | 실제 문제 | 처방 |
|---|---|---|
| "뭘 하라는 건지 모르겠어" | 첫 화면에 행동 유도가 없음 | 첫 화면 최상단에 한 줄 설명 + 큰 버튼 하나 |
| "저장하려니 로그인하래서 나갔어" | 로그인 시점이 너무 이름 | 로그인 없이 체험 → 저장 시점에만 요구 + 이유 설명 |
| "결과 나오는 데 오래 걸려" | 로딩 상태가 안 보임 | 진행 표시 + "보통 5초 걸려요" 안내 |
| "폰에서 글자가 작아" | 반응형 미흡 | 18강에서 처리 |

## 따라하기 4: 고치기

★ 항목 3개를 조각으로 만들어 TODO.md에 넣고, 10강의 리듬으로 하나씩. 하나 고칠 때마다 커밋 + push. 고친 뒤에는 **같은 사람에게 다시 보여주세요.** "아, 이제 알겠다"를 들으면 그 조각은 끝입니다.
