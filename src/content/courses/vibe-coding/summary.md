## 이 과정에서 만드는 것

코딩을 몰라도 **한국어로 AI에게 시켜서** 내 서비스를 하나 만들고, 인터넷에 공개하고, 폰 홈 화면에 설치하는 과정입니다. 총 20강, 약 13시간 분량이며 하루 한 강씩 20일 동안 진행합니다.

기본 도구는 **Claude 데스크탑 앱의 Code 탭**입니다. 말로 시키면 파일을 만들고 고치고 명령까지 실행합니다. 터미널(글자 명령 창)은 각 강의의 "터미널로도 할 수 있어요"로 보조 방법만 안내합니다.

매 강의는 같은 리듬입니다. **요청 → 비교 화면 읽기 → 브라우저에서 눈으로 확인 → 커밋(저장) → 안 되면 되돌리기.**

## 준비물

- 컴퓨터 한 대 (Windows 또는 macOS)와 인터넷
- **Claude 계정**: Code 탭을 쓰려면 Pro 이상 구독이나 API 결제 등록이 필요합니다.
- 가입할 서비스(대부분 무료): GitHub, Vercel, Supabase
- 13강에서 AI 기능을 붙일 때 쓸 AI API 키 (소액 결제, 월 5달러 정도면 충분. 무료 공개 API로 대체 가능)
- 사용자 3명 (17강. 지인이면 충분)
- 폰 한 대 (배포 주소 확인과 20강 설치용)
- 노트 한 권 (또는 메모 앱)

## 끝나면 할 수 있는 것

- 아이디어를 **한 장짜리 기획서**로 정리하고, 기능을 "하루에 끝나는 조각"으로 쪼갤 수 있습니다.
- AI에게 **구체적으로 요청**하고, 비교 화면을 읽어 수락과 거절을 판단할 수 있습니다.
- Git으로 **저장하고 망치면 되돌릴** 수 있어서 AI에게 과감하게 시킬 수 있습니다.
- 화면, 데이터 저장, 외부 API, 로그인이 있는 서비스를 **직접 만들어 배포**할 수 있습니다.
- 에러 메시지에서 **무슨 일 / 어디서 / 언제**를 뽑아 AI에게 정확히 보고할 수 있습니다.
- 사용자에게 보여주고 피드백을 받아 **우선순위를 정해 고칠** 수 있습니다.
- 서비스를 **폰 홈 화면에 설치되는 앱**으로 만들 수 있습니다.

## 막힐 때 기억할 세 가지

1. 에러 메시지를 **그대로 복사해서** AI에게 붙여넣는다.
2. 한 번에 하나만 바꾼다. 이상하면 **"마지막 커밋 상태로 되돌려줘"**.
3. 세 번 실패하면 요청을 더 **작게 쪼갠다.**
