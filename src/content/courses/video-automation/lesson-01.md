## 무엇을 만드나

이 과정은 **clay-episode-kit**이라는 공개 키트를 그대로 씁니다. 어떤 주제(과학·역사·생활·영단어·한자…)로도 한 편에 세 가지가 나옵니다.

| 결과물 | 내용 |
|---|---|
| 롱폼 | 16:9, 2~3분(인트로 6초 + 본편 + 엔딩 7초), 자막·키워드 카드 오버레이 |
| 쇼츠 | 9:16, 45초(첫 장면 중심), 위에 훅 제목띠·로고 |
| 썸네일 3종 | a(아이 얼굴+키워드판) · b(어른+문서카드) · c(얼굴 클로즈업, 단색 배경) |

등장인물은 클레이(점토) 애니메이션 스타일이고, 편이 달라도 같은 얼굴·같은 옷으로 고정됩니다 — `kit.config.json` 에 캐릭터 생김새를 문장으로 박아두기 때문입니다. 3강에서 직접 설정합니다.

## 6단계

```
① 대본  →  ② 더빙  →  ③ 컷 계획  →  ④ Flow 생성  →  ⑤ 조립·검사  →  ⑥ 업로드
  사람 작성   Typecast    사람 작성      Google Flow     ffmpeg·자동채점   Aside→Studio
```

| 단계 | 하는 일 | 도구 | 사람이 하는 것 |
|---|---|---|---|
| ① 대본 | 훅→반응→핵심→키워드→반전→복습→콜백 구조로 23~28줄 | 사람이 씀 (Claude Code 도움) | 내용·사실 확인 |
| ② 더빙 | 대본을 문장별 wav 로 | Typecast API | 목소리 선택, 호흡 확인 |
| ③ 컷 계획 | 대본 줄마다 어떤 6초 영상 컷을 보여줄지 + 영문 프롬프트 | 사람이 씀 (`top10_plan.py`) | **유일한 창작 단계** — 7강의 핵심 |
| ④ Flow 생성 | 6초 클립 10~12개 + 썸네일 이미지 3장 | Google Flow(Veo), Aside 로 조작 | 5분 대기, 빠진 컷 재제출 |
| ⑤ 조립·검사 | 클립+음성+자막+카드 합성, 자동 채점 | ffmpeg, `qa_gate.py` | 시트 한 장 눈으로 확인 |
| ⑥ 업로드 | R2 업로드 → 큐 → Studio 자동 입력 | Aside, R2 | 최종 공개 확인 |

## 도구 다섯 개와 비용

| 도구 | 역할 | 비용 |
|---|---|---|
| **Google Flow** | 영상 컷 생성(Veo) | **Google AI Pro 이상 구독**이 있어야 씁니다(월 크레딧 지급). 크레딧 **편당 110~130** (6초 컷당 10크레딧, 썸네일은 무료) |
| **Typecast** | 한국어 더빙 | 유료 플랜 + API 키(편당 24~28문장, 몇 분 분량) |
| **Cloudflare R2** | 완성 영상 임시 저장소 | 무료 티어로 충분 |
| **Aside** | 브라우저 자동화(Flow·Studio 조작) | 무료 플랜으로 시작 가능 |
| **ffmpeg** | 로컬 합성 | 무료 |

사람 손이 드는 시간은 **약 20분**, 기계가 도는 대기 시간은 **약 30분**입니다.

## 8강 쇼츠 과정과 무엇이 다른가

이 사이트에는 이미 "쇼츠 자동화"(8강) 과정이 있습니다. 완전히 다른 파이프라인이니 헷갈리지 마세요.

| | 쇼츠 자동화(8강) | 영상 자동화(이 과정) |
|---|---|---|
| 결과물 | 쇼츠 1개(80~100초, 4초×20~25컷) | 롱폼(2~3분) + 쇼츠(45초) + 썸네일 3종 |
| 그림체 | 대본마다 다름 | 클레이 애니, 캐릭터 고정 |
| 인물 일관성 | 컷마다 달라지기 쉬움 | 설정에 캐릭터 문구 고정 → 편이 달라도 같은 얼굴 |
| 검사 | 사람 눈으로 | 컷 계획·완성 영상·썸네일 자동 채점(8.0 미만 통과 못함) |
| 업로드 | YouTube Data API(쿼터 하루 6편) | Aside 로 Studio 조작(API 쿼터 안 씀), 큐 파일 |
| 실행 단위 | 대화로 하나씩 | 스킬(`/clay-episode`) 하나로 단계별 호출 |

두 과정을 같이 들을 필요는 없습니다. 롱폼 위주로 시작하고 싶다면 이 과정, 짧고 빠른 쇼츠 대량 생산이 목표라면 8강 쪽이 더 맞을 수 있습니다.

## 용어 5개

| 말 | 뜻 |
|---|---|
| **컷** | Flow 가 만드는 6초짜리 영상 조각. 한 편에 10~12개 |
| **컷 계획** | 대본 줄마다 어떤 컷을 보여줄지 + 각 컷의 영어 프롬프트를 담은 파이썬 딕셔너리 |
| **카드** | 화면 위 두 줄짜리 키워드 패널(예 「굴절 / 빛이 휘어져요」) |
| **QA 게이트** | 자동 검사. 컷 계획과 완성 영상 둘 다 8.0점 이상이어야 다음 단계로 |
| **큐·드레이너** | 업로드할 편을 텍스트 파일에 적어두면(큐) 스크립트가 순서대로 올리는(드레이너) 방식 |
