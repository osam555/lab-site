## 이 과정에서 만드는 것

주제 하나를 정하면 **롱폼(16:9, 2~3분) + 세로 쇼츠(45초) + 썸네일 3종**이 한 편으로 나오는 클레이 애니메이션 영상 파이프라인을 직접 돌려 봅니다. 공개 키트 `clay-episode-kit` 와 클로드 데스크탑 앱의 **Code 탭**을 쓰고, 터미널 명령은 접이식 보조로만 둡니다. 캐릭터 얼굴·옷은 설정 파일에 고정되어 편이 달라도 같은 인물이 나옵니다.

## 전체 흐름 (강별 한 줄)

| 강 | 한 줄 요약 |
|---|---|
| 1 파이프라인 한눈에 | 6단계(대본→더빙→컷 계획→Flow 생성→조립·검사→업로드)와 도구·비용을 설명만 듣고 확인 |
| 2 설치와 계정 | Python·Node·ffmpeg·키트·Typecast 키는 오늘, Aside·R2 는 5·6강 전까지로 나눠 준비 |
| 3 내 프로젝트 만들기 | `kit.config.json` 에서 캐릭터·채널·저장소 세 칸을 오늘 채움(나머지는 선택) |
| 4 첫 편 ① | 예시 대본 「무지개」로 더빙(4-1)과 컷 계획 검사 "10.0점 통과"(4-2) |
| 5 첫 편 ② | Flow 에 컷 11개·썸네일 3장 제출 → 받기·정리 → 빠진 컷 재제출 |
| 6 첫 편 ③ | 썸네일·조립(6-1) → 자동 검사·시트 눈 확인(6-2) → 업로드(6-3) |
| 7 내 주제로 쓰기 | 대본(7-1)·컷 계획(7-2)·썸네일 설계(7-3)를 내 주제로 직접 만듦 |
| 8 시리즈로 운영 | 두 번째 편 만들기, 여러 편 묶어 제출, 큐·드레이너, 주간 루틴 |

## 실습 결과물

- 1강: 클로드가 만든 6단계 표(내가 직접 대조)
- 2~3강: 설치 점검 표, `.env.local`, 내 `kit.config.json`
- 4강: 문장별 더빙 파일 24개, 컷 계획 "10.0점 통과"
- 5강: `assets/flow/rainbow/` 컷 mp4 11개 + 썸네일 a·b·c
- 6강: 롱폼·쇼츠 mp4, 시트 한 장, 유튜브에 올라간 첫 편
- 7~8강: 내 주제 대본·컷 계획, 두 번째 편, 주간 루틴표

## 준비물

| 것 | 설명 |
|---|---|
| 클로드 데스크탑 앱(Code 탭) | 모든 실습의 기본 도구 |
| Google AI Pro 이상 구독 계정 | Google Flow(영상 생성)에 필요. 편당 크레딧 110~130 |
| Typecast 유료 플랜 + API 키 | 한국어 더빙. 키는 `.env.local` 에만 저장 |
| Aside, Cloudflare 무료 계정(R2) | 브라우저 자동 조작, 완성 영상 임시 저장 |
| YouTube 채널 | 업로드 대상(업로드는 항상 사람이 최종 확인) |
| 시간 | 1~3강 약 2시간, 첫 편(4~6강) 약 2시간, 편당 사람 손 약 20분·기계 대기 약 30분 |

## 끝나면 할 수 있는 것

- 내 주제로 대본과 컷 계획을 쓰고, 자동 검사 점수를 눈으로 확인해 통과시킬 수 있다
- Flow 에 컷을 제출하고, 받은 파일을 정리하고, 빠진 컷만 재제출할 수 있다
- 롱폼·쇼츠·썸네일을 조립하고 시트의 4가지 체크포인트(가짜 글자·어두운 장면·카드 가림·인물 일관성)를 직접 검수할 수 있다
- 큐 파일로 여러 편을 올리고 하루 한도를 다음 날로 넘길 수 있다
- 막히면 에러 문구를 통째로 클로드에게 보여 주고 원인부터 설명받을 수 있다
