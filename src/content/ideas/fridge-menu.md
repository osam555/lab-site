## 누가 쓰나요
퇴근 후 배달 대신 집밥을 먹고 싶지만 뭘 만들지 매번 고민하다 결국 배달을 시키는 1인 가구 직장인.

## 어떤 문제
냉장고에 재료는 있는데 조합이 안 떠오른다. 레시피 사이트는 재료가 너무 많이 필요하다.

## 핵심 기능 3개
1. 재료를 입력한다 (칩 형태로 쌓임, 브라우저에 기억)
2. '추천받기'를 누르면 그 재료로 만들 수 있는 메뉴 3개 + 한 줄 설명 + 소요 시간
3. 마음에 든 메뉴를 저장하고 '내 메뉴'에서 다시 본다

## 성공 기준
내가 실제로 일주일 동안 이 앱으로 저녁 메뉴를 정한다.

## 안 만들 것
사진 업로드, 영양 정보, 장보기 목록, 소셜 공유.

## 조각 예시
- [ ] 재료 입력 + 칩 목록 (화면만)
- [ ] localStorage에 재료 기억
- [ ] 가짜 메뉴 3개 카드
- [ ] /api/recommend 서버 라우트 (AI API)
- [ ] 진짜 추천 연결 + 로딩/에러 상태
- [ ] Supabase saved_menus 테이블 + 저장 버튼
- [ ] /menus 목록 + 삭제
- [ ] 매직 링크 로그인 + RLS
- [ ] PWA

## 확장 아이디어 (20강 이후)
"이 메뉴 또 추천하지 마", 주간 식단표, 자주 쓰는 재료 자동 완성.
