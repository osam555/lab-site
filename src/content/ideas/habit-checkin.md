## 누가 쓰나요
습관 앱을 여러 개 깔았다 지운, "하나만 꾸준히" 하고 싶은 사람.

## 어떤 문제
기존 앱은 습관을 10개 등록하게 유도하고, 알림이 시끄럽고, 유료다.

## 핵심 기능 3개
1. 습관은 **하나만** 등록 (바꾸려면 기존 것을 끝내야 함)
2. 오늘 체크 버튼 하나 + 연속 일수 표시
3. 월 달력에 체크한 날 표시

## 성공 기준
30일 연속 체크에 성공한다 (앱을 만든 사람이 먼저).

## 안 만들 것
여러 습관, 알림, 통계, 공유, 목표 설정.

## 조각 예시
- [ ] 습관 등록 화면 (하나만)
- [ ] 오늘 체크 버튼 + 로컬 저장으로 먼저 동작
- [ ] checkins 테이블로 이동
- [ ] 연속 일수 계산 (오늘 또는 어제까지 이어지면 유지)
- [ ] 달력 뷰 (라이브러리 없이 직접, AI에게 시키면 30분)
- [ ] 로그인 + RLS
- [ ] PWA

## 왜 가장 짧은가
화면 2개, 테이블 2개. 20일 과정을 두 번째로 돌 때 "주말 안에 배포" 연습으로 좋습니다.
