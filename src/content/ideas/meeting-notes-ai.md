## 누가 쓰나요
회의록 담당인데 회의 끝나고 정리하는 데 30분씩 쓰는 사람.

## 어떤 문제
메모는 순서 없이 섞여 있고, 누가 뭘 하기로 했는지 다시 읽어야 알 수 있다.

## 핵심 기능 3개
1. 메모 붙여넣기 → AI가 "결정 사항 / 할 일(담당자, 기한) / 다음 회의 안건"으로 구조화
2. 정리 결과를 수정하고 저장 (원본 메모도 함께)
3. 회의 목록에서 "내 할 일"만 모아 보기

## 성공 기준
회의 후 정리 시간이 30분에서 5분으로 준다.

## 안 만들 것
음성 녹음/전사, 캘린더 연동, 팀 공유, 슬랙 알림.

## 조각 예시
- [ ] 메모 입력 화면 (큰 textarea)
- [ ] /api/summarize 서버 라우트 (AI API, JSON 응답 강제)
- [ ] 결과 화면: 세 섹션 + 수정 가능한 필드
- [ ] meetings / action_items 테이블 저장
- [ ] 회의 목록 + 상세
- [ ] 할 일 체크 + "내 할 일" 필터
- [ ] 로그인 + RLS
- [ ] 응답이 JSON이 아닐 때 재시도 (13강 '응답 파싱 실패')

## 왜 중급인가
AI 응답을 **구조화된 데이터**로 받아 테이블 두 개에 나눠 저장해야 합니다. 프롬프트 설계와 실패 처리가 핵심 학습 포인트입니다.
