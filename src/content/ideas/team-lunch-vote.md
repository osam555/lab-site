## 누가 쓰나요
매일 11시 30분에 "오늘 뭐 먹지" 메시지가 오가는 5~10명 팀의 총무 역할.

## 어떤 문제
채팅으로 후보를 모으면 흩어지고, 결정이 늦어지고, 매번 같은 사람이 정한다.

## 핵심 기능 3개
1. 투표 만들기: 제목 + 후보 3~5개 → 공유 링크 생성
2. 링크를 연 사람은 이름만 적고 한 표 투표 (로그인 없음)
3. 실시간으로 집계가 보이고, 마감 시간이 되면 결과 고정

## 성공 기준
우리 팀이 2주 동안 채팅 대신 이 링크로 점심을 정한다.

## 안 만들 것
식당 검색/지도, 결제, 알림, 계정.

## 조각 예시
- [ ] 투표 만들기 폼 (화면만)
- [ ] polls / options / votes 테이블
- [ ] 만들면 /p/[id] 링크 생성
- [ ] 투표 화면: 이름 + 선택 + 제출
- [ ] 중복 투표 방지 (브라우저 저장 기준, 완벽하지 않아도 됨)
- [ ] 집계 화면 (Supabase Realtime 또는 5초 폴링)
- [ ] 마감 시간과 결과 고정
- [ ] 폰 화면 정리

## 왜 입문에 좋은가
로그인이 없어서 12강까지의 내용만으로 완성됩니다. 실시간 갱신은 "5초마다 새로고침"으로 시작해도 충분합니다.
