## 화면은 다섯 구역만 알면 됩니다

```
┌──┬────────────┬──────────────────────┐
│액│ 탐색기      │ 편집기               │
│티│ (파일 목록)  │ (파일 내용)          │
│비│            │                      │
│티│            ├──────────────────────┤
│바│            │ 터미널               │
└──┴────────────┴──────────────────────┘
```

1. **액티비티 바** (맨 왼쪽 세로 아이콘): 탐색기, 검색, Git, 확장 전환
2. **탐색기**: 프로젝트 폴더의 파일 목록. 클릭하면 편집기에 열림
3. **편집기**: 파일 내용. 여러 탭을 열 수 있음
4. **터미널**: AI 코딩 도구와 대화하는 곳
5. **명령 팔레트** (`Ctrl/Cmd + Shift + P`): VS Code의 모든 기능을 검색으로 실행

## 외울 단축키 7개

이 7개면 마우스를 80% 덜 씁니다.

| 단축키 (Win / Mac) | 하는 일 |
|---|---|
| `Ctrl+P` / `Cmd+P` | 파일 이름으로 빠르게 열기 |
| `Ctrl+Shift+P` / `Cmd+Shift+P` | 명령 팔레트 |
| `Ctrl+\`` | 터미널 열기/닫기 |
| `Ctrl+B` / `Cmd+B` | 탐색기 접기/펴기 |
| `Ctrl+S` / `Cmd+S` | 저장 (AI가 고친 파일도 확인 후 저장) |
| `Ctrl+Z` / `Cmd+Z` | 되돌리기 |
| `Ctrl+Shift+F` / `Cmd+Shift+F` | 프로젝트 전체에서 글자 찾기 |

`Ctrl+Shift+F`는 특히 중요합니다. AI가 "어디를 고쳤다"고 하면 그 단어를 전체 검색해서 직접 확인하는 습관을 들이세요.

## 설정은 말로 바꿉니다

VS Code 설정은 사실 `settings.json`이라는 파일입니다. 메뉴를 뒤지는 대신 AI에게 말하면 됩니다.

터미널에서 AI 도구를 켜고 이렇게 요청해보세요.

> "VS Code 설정에서 글자 크기를 15로, 저장할 때 자동 정렬되게, 탭은 2칸으로 바꿔줘. settings.json을 직접 수정해줘."

AI가 파일을 열어 수정하고 무엇을 바꿨는지 알려줍니다. 마음에 안 들면 "글자 크기는 14로 돌려줘"라고 하면 됩니다.

## 있으면 좋은 확장 4개

액티비티 바의 확장 아이콘에서 검색해 설치합니다.

1. **Prettier** — 코드를 자동으로 보기 좋게 정렬
2. **ESLint** — 코드의 흔한 실수를 밑줄로 표시
3. **Error Lens** — 에러 메시지를 해당 줄 옆에 바로 표시 (디버깅에 큰 도움)
4. **Live Preview** 또는 브라우저 미리보기 — HTML을 바로 확인

이것도 AI에게 "위 4개 확장을 설치하는 명령어 알려줘"라고 하면 터미널 명령으로 한 번에 됩니다.

## 따라하기: 파일 하나 만들고 고쳐보기

1. AI에게: "index.html 파일을 만들고, 가운데에 '안녕하세요' 라고 크게 나오게 해줘."
2. 탐색기에서 `index.html`이 생겼는지 확인 → 클릭해서 내용 훑어보기
3. AI에게: "글자색을 초록색으로 바꿔줘."
4. `Ctrl+Shift+F`로 `green` 또는 `초록`을 검색해서 어디가 바뀌었는지 확인
5. 브라우저에서 파일을 열어 결과 확인

이 **요청 → 파일 확인 → 검색으로 검증 → 브라우저 확인** 순환이 앞으로 20일 동안 반복할 기본 동작입니다.

## 오늘의 체크리스트

- [ ] AI에게 settings.json을 수정시켜봤다
