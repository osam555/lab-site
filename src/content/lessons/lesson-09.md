## 매번 같은 말을 반복하고 있다면

8강까지 오면서 이런 말을 몇 번이나 했을 겁니다.

- "다른 파일은 건드리지 마"
- "한국어로 설명해줘"
- "Tailwind로 스타일해줘"
- "PLAN.md 참고해줘"

AI 코딩 도구는 대화가 새로 시작되면 이전 대화를 잊습니다. 그래서 프로젝트 폴더에 **규칙 파일**을 두면, 도구가 매번 자동으로 읽고 시작합니다. Claude Code는 `CLAUDE.md`, 다른 도구는 `AGENTS.md`나 `.cursorrules` 같은 이름을 씁니다. 역할은 같습니다: **신입 동료에게 주는 온보딩 문서**.

## 무엇을 적나요?

신입 개발자가 첫날 물어볼 것들을 적으면 됩니다.

### 1. 이 프로젝트가 뭔지
```markdown
# my-service

1인 가구 직장인을 위한 냉장고 재료 기반 저녁 메뉴 추천 서비스.
자세한 기획은 PLAN.md 참고.
```

### 2. 기술 스택
```markdown
## 기술
- Next.js (App Router), TypeScript, Tailwind CSS
- 데이터: (12강에서 추가)
- 배포: Vercel, main 브랜치에 push하면 자동 배포
```

### 3. 작업 규칙
```markdown
## 작업 규칙
- 요청한 파일만 수정한다. 다른 파일을 고쳐야 하면 먼저 물어본다.
- 새 라이브러리 설치가 필요하면 이유를 설명하고 허락을 받는다.
- 기능 하나가 끝나면 브라우저에서 확인하는 방법을 3단계로 알려준다.
- 설명은 한국어로, 짧게, 코드 먼저.
```

### 4. 하지 말 것
```markdown
## 하지 말 것
- PLAN.md의 "안 만들 것"에 있는 기능을 추가하지 않는다.
- .env 파일의 내용을 출력하거나 코드에 복사하지 않는다.
- 테스트 목적으로 실제 데이터를 삭제하지 않는다.
```

### 5. 자주 쓰는 명령
```markdown
## 명령
- 개발 서버: npm run dev
- 빌드 확인: npm run build
```

## 따라하기: 내 CLAUDE.md 만들기

AI에게 시키세요.

> "PLAN.md를 읽고, 이 프로젝트의 CLAUDE.md를 만들어줘. 항목은 '프로젝트 소개, 기술, 작업 규칙, 하지 말 것, 명령' 5개. 작업 규칙에는 '요청한 파일만 수정', '새 라이브러리는 허락 후 설치', '완료 후 확인 방법 3단계 안내', '한국어로 짧게'를 넣어줘."

만들어진 파일을 **직접 읽어보고** 고치세요. 이 파일만큼은 여러분이 내용을 다 알아야 합니다.

## 효과 확인하기

새 대화를 시작하고 규칙을 전혀 언급하지 않은 채 요청해보세요.

> "메뉴 카드 컴포넌트 만들어줘."

AI가 알아서 한국어로 짧게 설명하고, 다른 파일을 안 건드리고, 확인 방법을 알려주면 성공입니다.

## 키워 나가기

CLAUDE.md는 한 번 쓰고 끝이 아닙니다. AI가 같은 실수를 두 번 하면 그때마다 한 줄 추가하세요.

- AI가 자꾸 영어 주석을 달면 → "주석은 한국어로"
- AI가 자꾸 `any` 타입을 쓰면 → "TypeScript any 사용 금지"
- AI가 파일을 이상한 폴더에 만들면 → "컴포넌트는 src/components/ 에"

3주 뒤 이 파일은 여러분 프로젝트의 가장 귀한 문서가 되어 있을 겁니다.
