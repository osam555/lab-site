## 스킬이란

**스킬(Skill)**은 자주 쓰는 파이프라인을 파일로 저장해두는 방법입니다.

- 규칙 파일(CLAUDE.md)이 "항상 지켜야 할 것"이라면
- 스킬 파일은 **"이 명령이 들어오면 이렇게 실행해"**

SNS 배포, 유튜브 업로드, 블로그 포스팅 같은 반복 작업을 스킬로 만들면 다음부터는 주제·내용만 입력하면 됩니다.

---

## 파일 위치

```
프로젝트 폴더/
  .agents/
    skills/
      sns-deploy/
        SKILL.md      ← SNS 배포 스킬
      youtube-upload/
        SKILL.md      ← 유튜브 업로드 스킬
      blog-post/
        SKILL.md      ← 블로그 포스팅 스킬
```

---

## SKILL.md 형식

```markdown
---
name: SNS 배포
description: 원본 콘텐츠를 5개 채널 형식으로 변환하고 예약 배포합니다.
---

# SNS 배포 스킬

## 입력값
사용자가 제공하는 것:
- 원본 내용 (텍스트)
- 이미지 경로 (없으면 생략)
- 예약 날짜와 시간

## 실행 단계
1. sns-rules.md를 읽어서 채널별 규칙 파악
2. 채널별 텍스트 변환 (인스타·X·스레드·카카오채널·알림)
3. 인스타용 이미지 카드 생성
4. Computer Use로 인스타·카카오채널 예약
5. X·스레드 텍스트를 클립보드에 복사

## 완료 보고
각 채널 처리 결과를 표로 정리해서 보고한다.
```

---

## 스킬 호출 방법

> **SNS 배포 스킬을 써줘.**
> 원본: 이번 주 토요일 플리마켓 참가. 핸드메이드 소품 20% 할인.
> 이미지: images/market.jpg
> 예약: 금요일 오후 6시

Claude Code가 `.agents/skills/sns-deploy/SKILL.md`를 읽고 전체 파이프라인을 실행합니다.

---

## 만들면 좋은 스킬 예시

| 스킬 이름 | 호출 한 줄 | 자동 실행 내용 |
|---|---|---|
| SNS 배포 | "SNS 배포 스킬 써줘" | 5채널 변환·이미지카드·예약 |
| 유튜브 업로드 | "유튜브 업로드 스킬 써줘" | 키워드·썸네일·Studio 예약 |
| 블로그 포스팅 | "블로그 포스팅 스킬 써줘" | 리서치·초안·에디터 입력 |
| 이미지 최적화 | "이미지 최적화 스킬 써줘" | WebP 변환·리사이즈·정리 |
| 주간 리포트 | "주간 리포트 스킬 써줘" | 서치 콘솔·인사이트 요약 |

## 스킬 만드는 법

> .agents/skills/[스킬이름]/SKILL.md를 만들어줘.
> 이 스킬이 하는 일: [파이프라인 설명]
> 입력값: [사용자가 매번 제공하는 것]
> 실행 단계: [순서대로]

Claude Code가 SKILL.md를 작성합니다. 한 번 테스트 후:

> 스킬이 잘 작동했어. sns-deploy SKILL.md에 인스타 최적 예약 시간(오후 7시)을 기본값으로 추가해줘.

## 스킬 vs 규칙 파일 차이

| | 규칙 파일 (CLAUDE.md) | 스킬 (SKILL.md) |
|---|---|---|
| **역할** | 항상 지켜야 할 규칙 | 특정 명령 실행 절차 |
| **발동** | 모든 대화에 자동 적용 | 명시적으로 호출할 때만 |
| **내용** | 금지 사항, 코딩 스타일, 언어 | 단계별 실행 지침 |
| **예시** | "주석은 한국어로" | "SNS 배포할 때는 이 순서로" |
