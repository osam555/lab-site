키 문제입니다. 순서대로:

1. `.env.local`의 키 앞뒤에 **공백이나 따옴표**가 없는지
2. `.env.local` 수정 후 `npm run dev`를 **재시작**했는지
3. 서버 라우트에서 `process.env.키이름`의 이름이 파일과 **정확히 같은지** (대소문자)
4. 배포에서만 401이면 **Vercel 환경변수**에 추가했는지

키 값을 AI에게 보여주지 말고, "키 이름이 맞는지만 확인해줘"라고 하세요.
